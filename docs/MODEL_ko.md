# AuralPaths

확성 공연을 위한 경로 분리형 바이노럴 시뮬레이터. LABO 1557.

> 이 문서는 `MODEL_en.md`(영어)의 한국어 번역이다. 내용이 다를 경우 영어 원문을 기준으로 한다. 버튼 이름 등 화면 표기는 실제 화면과 같도록 영어 그대로 두었다.

홀(슈박스, 또는 평면 외곽선에 바닥선·천장선을 그린 홀)에 **확성 음원**(직접음 + 좌우 PA 한 쌍), 임의 개수의
**비확성 음원**(직접음만), 청취 좌석을 배치한다. 음원–좌석 쌍마다 경로별 바이노럴 실내 임펄스 응답(BRIR)을
만들고, 명목 ITDG(초기 반사음 지연 시간)와 레벨비 조건을 적용한 뒤 도달 시간, 레벨, 실내음향 지표를 보고한다.

> `config.json`의 홀 크기와 흡음률은 임시값이다. 이 숫자를 실제 홀의 특성으로 읽지 말 것.

## 실행 (macOS)

```bash
pip install pyroomacoustics sofar soundfile scipy matplotlib
# hrir/KU100.sofa = Zenodo 레코드 3928297의 HRIR_FULL2DEG.sofa (Bernschütz 2013)
python run.py                    # Python 기준 계산 + out/viewer.html
python hall/make_hall.py         # 기준 홀 도면 (평면 + 단면)
python test_signals/make_sines.py
```

그린 홀은 `config.json`에 `geometry` 블록(plan, floor, ceiling, materials, ism_order, rays)으로 들어간다.
뷰어의 **Copy config**가 이 블록을 써 준다. `examples/fan_hall_config.json`은 경사 객석이 있는 가상의 부채꼴
홀이다: `python run.py examples/fan_hall_config.json` (약 1.5분, `out_fan/`에 출력).

자신의 홀은 홀마다 별도 폴더에 `config.json`과 `out/`을 두고 관리한다
(예: `python run.py my_hall/config.json`). 홀 도면과 트레이스한 홀 config는 이 저장소에 포함되지 않는다.

브라우저에서 `out/viewer.html`을 연다. SOFA 파일이 없으면 `run.py`는 무지향 RIR과 평면도만 출력한다.

## 뷰어 (`out/viewer.html`)

페이지가 모든 BRIR을 스스로 다시 계산하므로, 아래 기능은 Python을 다시 실행하지 않아도 동작한다.

- **홀 형상**: **Shoebox** 또는 **Drawn hall**. 그린 홀은 평면 외곽선(임의의 다각형, 예: 부채꼴)에 깊이 방향의
  바닥선과 천장선(경사 객석, 단, 계단형·경사 천장)을 더한 것이다. 불러온 도면 위에 따라 그린다.
  - **Trace outline** (평면): 안쪽 모서리를 클릭한다. 첫 점을 클릭하거나 더블클릭 또는 Enter로 닫는다.
    Backspace는 되돌리기, Esc는 취소. 스스로 교차하는 외곽선은 거부된다. **Edit corners**로 모서리를 끌어 옮긴다.
  - **Trace floor / Trace ceiling** (단면): 홀 뒤쪽(왼쪽)에서 무대(오른쪽) 방향으로 클릭한다. 직전 점과 깊이가
    15 cm 이내인 클릭은 수직 단이 된다. 천장은 바닥보다 최소 1.5 m 높아야 한다.
  - 재료 4종(객석 바닥, 무대 바닥, 벽, 천장), 옥타브 대역별 α와 산란계수 s.
  - 허상 차수(기본 4)와 광선 수(초안 10k ~ 100k)로 속도와 잡음의 균형을 정한다.
  - 폭/깊이/높이는 도면의 틀이며, 트레이스한 형상은 이에 맞춰 늘어나고 줄어든다.
  - 배치 표의 높이는 그 위치의 바닥 기준이므로 좌석이 객석 경사를 따른다.
  - **Dimensions**는 평면에 벽 길이, 단면에 바닥·천장 높이를 표시한다(m).
- **반자동 트레이스 (어느 사본에서나 동작, Claude 불필요):**
  1. 평면(과 단면)을 불러온다. 맞춤 단계에서 **Set scale…**을 누르고, 길이를 아는 치수선의 양 끝을 클릭한 뒤
     (PDF에서는 클릭이 선의 끝점에 붙는다) 길이를 m 단위로 입력한다. 그러면 박스가 홀의 폭과 깊이를 정한다
     (단면: 높이, 그리고 평면에 축척이 없으면 깊이). 축척이 없으면 박스는 현재 크기에 맞춰 늘어난다.
  2. 위와 같이 트레이스한다. **Snap to drawing**이 켜져 있으면(기본값) 각 클릭은 화면 10픽셀 이내에서 PDF 자체
     선의 가장 가까운 모서리·교차점으로, 없으면 가장 가까운 선 위로, 그것도 없으면 5 cm 격자로 간다. 커서가 어느
     경우인지 보여 준다(□ = 모서리, ○ = 선, + = 격자). **Alt**를 누르고 있으면 자유롭게 찍힌다.
     **Edit corners**도 같이 붙는다.
  3. 벡터 선은 CAD에서 내보낸 PDF에만 있다. PNG / JPG / 스캔 PDF는 5 cm 격자를 쓴다.
  확인: 그리기 선 22 908개가 있는 CAD 평면 PDF에서, 선 근처 무작위 40회 마우스 위치가 모두 모서리에 붙었다.
  Alt를 누르면 붙지 않는다.
- **Auto-trace from PDFs…** (Claude 안에서 연 웹 버전 전용. Claude에게 도면을 읽게 하며 뷰어 사용자의 Claude
  사용량을 쓴다): 평면 및/또는 단면을 고른다. 약 1–3분.
  1. 페이지가 각 시트를 렌더링하고 PDF의 그리기 선을 모두 읽는다.
  2. Claude가 시트 전체를 읽는다: 방향, 실, 치수 문자열 2–4개.
  3. 축척 = 양 끝을 그려진 치수 보조선에 붙인 치수들 (치수끼리 일치해야 한다).
  4. Claude가 실 부분을 잘라 낸 이미지에서 외곽선(평면) 또는 바닥·천장선(단면)을 트레이스한다.
  5. 트레이스한 각 변을 0.3 m 이내의 가장 가까운 평행한 그리기 선에 붙이고, 모서리는 선의 교점으로 다시 만든다.
  6. 선택적 2차 과정: Claude가 4개의 2배 확대 타일 위에 그려진 자기 트레이스를 보고 점을 수정하며, 수정된 점을
     다시 붙인다(0.2 m).
  7. 평면과 단면을 무대 앞선 기준으로 맞추고, 두 도면을 결과 아래에 깐다.
  Claude가 단순화한 내용이 목록으로 표시된다. **Undo auto-trace**는 이전 홀로 되돌린다.
  한계: 정밀도는 Claude가 시트를 얼마나 잘 읽느냐에 달려 있다. 벽은 PDF에 벡터 선이 있는 곳에서만 붙는다
  (PNG / JPG는 Claude가 정한 위치 그대로). 단면의 계단식 객석이 가장 어렵다(단 바로 아래에 구조선이 있다).
  항상 겹쳐 그린 결과를 확인하고 Edit corners나 재트레이스로 고칠 것.
- **Hall**: 폭, 깊이, 높이, 무대 깊이, 옥타브 대역별 흡음률. 무대 깊이는 입력하는 동안 무대 경계를 미리 보여 주고
  Enter로 적용된다.
- **도면**: 평면도(위에서 본 그림)와 단면도(옆에서 본 그림, 무대가 오른쪽)를 따로 불러올 수 있다. 파일 선택,
  버튼, 또는 평면/단면 위로 끌어다 놓기. PDF(첫 페이지), PNG, JPG, SVG를 받는다. 불러온 뒤 맞춤 단계에서 시트를
  회전·반전하고 홀 안쪽을 박스로 지정한다. 박스는 실 내부에 맞춰 늘어난다. **Adjust…**로 다시 연다. 페이지는 빈
  실로 시작하며, 파일 없이 **Show drawing**을 누르면 홀 크기와 무대 깊이를 따르는 내장 개략도(좌석, 무대 경계)가
  보인다.
- **크기 변경 시**: 잠기지 않은 항목은 홀과 함께 움직이거나(x는 폭에 비례, 무대 위 항목은 무대와 함께, 좌석은 객석
  깊이에 비례, 높이는 그대로) 제자리에 남는다.
- **조건**: 명목 ITDG 0–60 ms(1 ms 단위), 레벨비 −9 ~ +6 dB(0.5 dB 단위). 슬라이더나 직접 입력. A/B 입력도 같은
  범위다. Python 기준값은 `config.json`의 격자(`conditions`: ITDG 0 / 20 / 40 / 60 ms × 레벨비
  −9 / −6 / −3 / 0 / +3 / +6 dB)에만 있다. 추세 그래프는 레벨비 전 범위에 걸쳐 ITDG 0 / 20 / 40 / 60 ms를
  그리며, 원 표시는 현재 조건이다.
- **PA 조준**: PA마다 커버리지(Omni, 120°, 90°, 60°), 방위각(0° = 홀 정면 방향, + 는 +x 쪽), 고도각(+ 는 위).
  **Aim at seat**는 선택한 좌석을 향하게 한다. `config.json`에서는 `B_L` / `B_R`에
  `"coverage": 90, "aim": {"az": 29.7, "el": -1.4}`.
- **배치**: 평면에서 음원, PA, 좌석을 끌어 옮기거나 x/y/z를 입력한다. 항목별로 또는 한꺼번에 잠글 수 있다.
  **Reset layout**은 `config.json` 상태로 되돌린다.
- **좌석 지도** (config에 `"seats"` 목록이 있는 홀. 예: 평면도에서 좌석을 하나씩 트레이스한 경우): 모든 좌석을
  평면에 그리고, 실효 ITDG(가장 가까운 PA − 확성 직접음) 또는 레벨비 추정값으로 색을 칠한다. PA가 먼저 도달하는
  좌석에는 주황색 원이 붙는다. 마우스를 올리면 좌석의 x/y/z, B_L·B_R 경유 ITDG, 추정값이 보인다. **좌석을 클릭하면
  L / C / R 중 하나가 그 자리로 옮겨진다**(메뉴에서 선택). **Copy seat CSV**는 현재 조건의 값을 복사한다.
  레벨 추정값은 기준 좌석의 레벨비에 그 좌석과 기준 좌석 사이의 직접음 차이(1/r²과 PA 지향성, 500 / 1000 Hz)를
  더한 값이다. 좌석마다 실내 시뮬레이션을 한 것이 아니며, L / R 위치에서는 BRIR 에너지비와 최대 약 1.5 dB 차이가
  난다(`run_log.txt` 참조).
- **비확성 음원**: 최대 5개까지 추가, 아무것이나 삭제 가능.
- **Listen**: 확성 음원용 드라이 파일 1개, 비확성 음원마다 1개. Mix / Direct only / PA only. 헤드폰 청취.
  **Sennheiser HD600 compensation**(config에 헤드폰 필터가 지정되어 있으면 기본으로 켜짐)은 출력을 Sennheiser
  HD600 보정 필터에 통과시켜 바이노럴 신호를 그 헤드폰에 맞게 등화한다. 다른 헤드폰이나 스피커에서는 끈다.
- **Save config…** (Load config 옆): 현재 config 전체를 내려받는다(`<hall>_config_edited.json`). 페이지가 만들어진
  config(또는 불러온 config)에 현재의 홀, 음원, 조준, 지향성 데이터, 좌석을 반영한 것이다. AuralPaths 폴더에 넣고
  `python run.py <파일>`을 실행한다. **Copy config**는 같은 JSON을 복사한다.
- **Load config…**: config JSON을 연다(예: `my_hall/config.json`. 평면 위에 끌어다 놓아도 된다). 페이지가 그 홀,
  재료, 음원, 좌석으로 바뀐다. **Reset to config**는 페이지가 만들어진 config로 되돌린다.

형상이 `config.json`과 일치하는 동안에는 브라우저 값 옆 괄호 안에 Python 기준값이 표시된다.

## 모델

### 슈박스

| 부분 | 방법 |
|---|---|
| 초기부 (직접음 + 100 ms) | 12차까지의 슈박스 허상(pyroomacoustics의 감쇠와 공기흡음), 허상마다 가장 가까운 KU100 HRIR, 분수 지연 |
| 후기부 | 허상 에너지 포락선(60차, 비간섭 합, 5 ms 평활)으로 성형한 옥타브 대역 잡음 × 확산음장 HRTF 대역 이득. 경로마다 독립 잡음. 좌우 잡음은 KU100 세트의 확산음장 양귀 상관 Γ(f)를 갖는다(아래 참조) |
| 연결 | sin² 교차 페이드 10 ms, 직접음 + 100 ms에서 시작 |
| PA 지향성 | 일반적인 축대칭 패턴(공학적 가정이며 실측 스피커가 아님): 2 kHz 이상에서 공칭 −6 dB 전각, 그 아래에서는 BW(f) = min(360°, coverage·max(1, (2000/f)^0.7))로 넓어진다. 진폭 ((1 + cos θ)/2)^n, BW/2에서 −6 dB, 하한 −30 dB. 모든 허상에 정확히 적용한다(방사 방향 = 첫 반사점 방향). 광선추적 확산 성분은 패턴의 평균 에너지 1/(2n + 1)로 조정한다. 극좌표 데이터로 대체할 수 있다("데이터 기반 스피커 지향성" 참조) |
| 조건 | 기준 좌석 C: PA 지연 = 명목 ITDG − (PA 도달 − 확성 직접음 도달). PA 게인으로 바이노럴 에너지비를 맞춘다 |
| 지표 | C80, D50, Ts, EDT, T30은 확성 체인의 합산 에너지 히스토그램(500 + 1000 Hz 옥타브 평균)에서. IACC E3은 0–80 ms 바이노럴 합에서. Python은 IACC L(80 ms ~ 끝, 500 / 1k / 2k Hz)과 125 / 250 Hz의 IACC L도 출력한다 |

실내음향 지표는 비간섭 허상 에너지 합을 쓴다. 완전히 규칙적인 슈박스 격자로 합성한 무지향 파형을 대역 필터링하면
후기 에너지가 부풀려지는 것이 확인되어(임시 홀에서 500 Hz +9.6 dB) 더 이상 쓰지 않는다.

### 그린 홀

| 부분 | 방법 |
|---|---|
| 면 | 평면 다각형 × 바닥/천장 단면 → 평면 다각형들(바닥 띠, 단의 수직면, 천장 띠, 단면 꺾임에서 나뉜 벽) |
| 경면 반사 | 지정 차수까지의 허상. 각 경로를 반사 다각형들을 거쳐 역추적하고 가림을 검사한다(볼록하지 않은 실). 첫 100 ms를 KU100 HRIR로 렌더링 |
| 확산 | 확률적 광선추적: 파워 4π/N의 광선 N개, 확률 s로 Lambert 반사, 수음 구 r = 0.5 m. 허상과 같은 에너지 단위의 히스토그램 |
| 결합 | 총 에너지 = 허상 + max(0, 광선 − 허상)(10 ms 평활). 잔여분은 초기 창 안에 잡음으로 더한다(두 엔진 모두. Python은 이번 버전부터이며, 그 전에는 Python BRIR의 첫 100 ms에 이 에너지가 빠져 있었다. 약 0.5–1 dB). 총 에너지가 후기 잡음을 성형한다 |
| Python 기준 | 같은 면을 pyroomacoustics(허상 + 자체 광선추적)에 넘긴다. `config.json`의 `geometry` 블록 |

확인: 슈박스에서 브라우저의 허상이 pyroomacoustics와 정확히 일치하고(허상 62개), 광선추적 히스토그램은 해석적
에너지와 ±1 dB 이내로 맞는다. 단이 있는 볼록하지 않은 부채꼴 홀(면 31개)에서도 허상 목록이 pyroomacoustics와
정확히 일치한다. s = 0인 직사각형 그린 홀은 슈박스를 재현한다(T30 1.54 / 1.54 s, EDT 1.18 / 1.20 s,
C80 2.05 / 2.21 dB). s = 0.1이면 감쇠가 짧아진다(T30 1.29 s). 그린 홀은 산란을 모델링하고 슈박스는 하지 않기 때문이다.

부채꼴 시험 홀에서 브라우저 대 Python(좌석 3곳, 광선 50 000개, 서로 다른 난수 광선): C80 0.7 dB, D50 0.04,
Ts 7 ms, EDT 0.10 s, T30 0.05 s, IACC E3 0.10 이내. EDT와 C80 차이는 통상의 JND 부근이므로, 좌석 하나에서 약
1 dB 미만의 C80 차이는 광선추적 잡음으로 읽을 것. 최종 수치에는 광선 수를 늘린다. (아래 공기흡음 수정 전에 측정한
값이며, 이 수정은 500 Hz–1 kHz의 Python 값을 0.5 dB 미만으로 바꾼다.) 수정 후 BRIR 에너지 브라우저 대
Python(그린 시험 홀 2개, 24경로): 첫 100 ms 1.0 dB, 120–300 ms 0.9 dB, 0.3–1.6 s 1.8 dB 이내(잡음과 광선이 서로
독립).

### 모서리 회절 (1차, UTD)

그린 홀 전용, 두 엔진 모두(`diffraction.py`, `GEOM.edges` / `GEOM.diffract`. 두 구현은 1e-10 이내로 일치).
방법: 균일 회절 이론(UTD), Kouyoumjian & Pathak (1974), "A uniform geometrical theory of diffraction for an edge
in a perfectly conducting surface", Proc. IEEE 62, 1448–1461
([Google Scholar](https://scholar.google.com/scholar?q=A+uniform+geometrical+theory+of+diffraction+for+an+edge+in+a+perfectly+conducting+surface)).
실내음향에 적용한 형태는 Tsingos, Funkhouser, Ngan & Carlbom (2001), SIGGRAPH,
[doi:10.1145/383259.383323](https://doi.org/10.1145/383259.383323)를 따른다: 구면파 입사, 강체 쐐기면이며 각 면의
반사항에 R = √(1 − α)를 곱한다(Tsingos 등과 같은 경험적 처리).

| 항목 | 선택 |
|---|---|
| 모서리 | 두 면이 공유하는 모든 직선 모서리 중 실내 쪽 각도가 180°를 넘는 것(단 윗모서리, 무대 립, 천장 단차, 평면의 안쪽으로 꺾인 모서리, 2° 이상의 볼록한 단면 꺾임). 오목 모서리에는 1차 항이 없다 |
| 경로 | 음원 → 모서리 위 회절점(Keller 원뿔, 최단 경로) → 수음점. 두 구간 모두 가림을 검사 |
| 계수 | 32개 주파수(16 Hz–24 kHz)의 복소 UTD 계수. 전이 함수 F(X)는 멱급수(X ≤ 16)와 점근 급수(X > 16)로 계산 |
| 렌더링 | 모서리마다 도달음 1개, 회절점 방향의 HRIR. 복소 스펙트럼을 경로 지연과 함께 적용 |
| 에너지 | 같은 경계의 기하 도달음(직접음, 쐐기 두 면에서의 반사)과의 간섭까지 포함해 허상 히스토그램에 더한다. 옥타브 대역마다 8개 주파수로 평균 |
| 켜고 끄기 | `geometry` 블록의 `"diffraction": false`, 또는 뷰어의 *Edge diffraction* |

확인(무대 립, 1 m 단, 음원은 무대 위 0.3 m): 직접음의 그림자 경계를 가로질러 에너지가 연속이다(경계 바로 아래 /
위에서 250 Hz −1.0 / −0.9 dB, 1 kHz −1.7 / −1.7 dB, 4 kHz −3.0 / −2.9 dB). 회절이 없으면 0 dB에서 0으로 끊긴다.
반무한 평판 시험: 전체 음장이 그림자 경계를 가로질러 연속이며, 고주파에서 자유 음장 진폭의 절반으로 수렴한다.

실측 확인, BRAS RS5(`validate_bras.py`, 결과는 `validation/bras_RS5.*`): 단단한 바닥 위 높이 2.07 m 칸막이의 RIR 16개
(스피커 높이 4 × 마이크 높이 4)를, 칸막이 측면 모서리 경유음이 오기 전에 끝나는 창 안에서 UTD + 바닥 영상과
1/3옥타브 대역으로 비교했다. 500 Hz–2 kHz 평균 절대 차이: 그림자 위치 11개 2.2 dB, 전체 16개 1.8 dB.
250 Hz–8 kHz는 2.1 / 1.8 dB. 예측 레벨은 평균 0.1–1.9 dB 높으며(그림자 영역 5 kHz 이상에서 더 크다), 여기에는
모델이 빠뜨린 것이 포함된다: 스피커의 응답과 지향성(1 kHz 교정값만 사용), 칸막이 두께 25 mm, 공기흡음. 네 경로의
간섭 패턴(낮은 스피커에서 1 kHz와 3 kHz 부근의 dip)이 재현된다. 음원이나 수음점이 바닥 높이인 IR 3개
(LS4-MP1, LS1-MP2, LS4-MP2)에서는 회절 경로보다 먼저, 직선 거리에 해당하는 시간에 소리가 도달한다. 칸막이를 통한
투과로 보이며(BRAS 문서에도 언급), 이는 모델링하지 않는다. LS4-MP2는 창도 1 ms뿐이다. 그 밖의 경우 도달 시간은
0.1 ms 이내로 일치한다.

모델링하지 않은 것: 고차 경로(반사와 결합된 회절, 모서리 간), 모서리 끝점 회절, 2.5D 모델에 없는 물체의 모서리
(좌석, 발코니 앞면, 반사판). 반사 계수 가중은 흡음 쐐기의 해가 아니다.

### 방향성 후기 음장

이전에는 후기 잡음이 이상적 확산음장의 양귀 에너지와 양귀 상관을 썼다. 이제는 후기음이 실제로 도래하는 방향에서
이를 구한다(그린 홀).

1. 광선추적이 수음점마다 직접음 + 100 ms 이후 64개 방향 칸(피보나치 구, 머리 좌표) 각각에서 도달하는 에너지를
   옥타브 대역별로 기록한다(`dirrays.py`, 음원당 광선 20 000개, 수음 구 1 m. 브라우저에서는 자체 광선추적이 같은
   칸을 채운다).
2. ρ_d = 칸당 에너지 / 그 칸의 HRIR 면적 가중이라 하면, 대역별 귀 에너지 = Σ ρ_d·BE_d / Σ ρ_d·Ω_d,
   상관 Γ(f) = Σ ρ_d X_d / √(Σ ρ_d P_L,d · Σ ρ_d P_R,d)이다. BE, X, P는 각 칸에 속한 KU100 방향들의 합이다
   (`late_dir_tables`). Γ는 복소수이며 오른쪽 채널이 그 위상을 받는다.
3. 그 상관을 갖는 잡음 쌍(위와 같은 혼합)을 대역마다 하나씩 만들고, 이전과 같이 에너지 히스토그램으로 성형한다.

균일한 음장이면 정확히 확산음장 값이 된다(확인: 6e−15). 후기 에너지 전체와 그 감쇠는 여전히 에너지 히스토그램에서
오며, 양귀 사이의 배분과 상관만 바뀌었다. 시드에 따른 후기 ILD 편차: 약 0.1 dB(광선 20 000개, 1 m 구. 0.5 m에서는
0.3–0.4 dB). 후기부 전체에 방향 분포 하나(시간에 따른 방향 변화 없음). 방향 계산에서는 음원을 무지향으로 본다.
슈박스는 여전히 확산음장. 켜고 끄기: `binaural`의 `"late_directional": false`.

### 광선추적 에너지의 공기흡음 (수정됨)

pyroomacoustics 0.10은 광선추적 히스토그램에서 공기흡음을 빠뜨린다(확인: `air_absorption`이 있을 때와 없을 때의
히스토그램이 동일). RIR을 합성할 때만 적용한다. 이제 `energy_hist`가 칸마다 exp(−m c t)를 적용한다. 수정 전에는
그린 홀의 Python 후기 에너지가 고주파에서 너무 높았고(그린 시험 홀, 직접음 후 0.1–1 s: 4 kHz +2~+3 dB,
8 kHz +6~+11 dB, 500 Hz–1 kHz 최대 +0.5 dB), 그 때문에 2 kHz 이상에서 그린 홀의 Python T30 / EDT가 너무 길고
후기부가 너무 밝았다. 이제 브라우저와 Python 히스토그램은 모든 대역에서 0.5 dB 이내로 일치한다(그린 시험 홀, 경로 1개).
슈박스 모델은 영향을 받지 않았다.

### 후기 양귀 상관

목표: Γ(f) = Re Σ w·H_L·H_R* / √(Σ w·|H_L|² · Σ w·|H_R|²), KU100 전 방향(면적 가중)에 대해. 즉 이 머리에 대한
이상적 확산음장의 양귀 상관이다. 두 독립 잡음 n1, n2를 주파수마다 L = cos a·n1 + sin a·n2,
R = cos a·n1 − sin a·n2, a = arccos(Γ)/2로 섞는다(상관 = Γ, 단위 파워. Habets, Cohen & Gannot 2008, JASA 124(5),
doi:10.1121/1.2987429의 2채널 경우).
확인: 무작위 방향의 평면파 3000개를 KU100 HRIR로 렌더링한 음장과 1/3옥타브 상관이 0.07 이내로 같다. KU100에서
Γ는 125 Hz에서 약 0.9, 250 Hz에서 0.65, 500 Hz 이상에서 0에 가깝다. 따라서 변화는 주로 500 Hz 미만에서 나타나며
(125 Hz 후기 IACC가 약 0.2에서 0.9로 상승), 표준 500–2000 Hz 대역의 IACC L은 거의 변하지 않는다.

## 청취 실험용 자극 (`make_stimuli.py`)

`python make_stimuli.py examples/stimuli_example.json`은 경로 분리 BRIR(`{seat}_{path}.wav`, 헤드폰 EQ 없음)에서
모든 자극을 만든다. 같은 스크립트를 두 단계에 모두 쓰도록 되어 있다: AuralPaths BRIR(`out/brir/`)과 같은 방식으로
이름 붙인 KU100 실측 BRIR. 따라서 두 단계의 차이는 BRIR의 출처뿐이다.

- 경로 A = `path_A_inputs`의 합(예: 보컬 + 피아노)을 BRIR A에 통과. 경로 B = `path_B_inputs`의 합(보컬)을
  B_L + B_R에 통과.
- ITDG는 기준 좌석에서 BRIR 시작점(피크 대비 −20 dB 이내 첫 샘플, 먼저 오는 귀. B = B_L, B_R 중 이른 쪽)으로
  설정한다. 정수 샘플 지연. 음의 전기적 지연은 홀에서 실현할 수 없으므로 경로 A를 지연시켜 구현하고 표시한다.
- 레벨비는 연구계획서의 정의대로 기준 좌석에서 설정한다: 자극 전체에 걸친 귀 신호의 RMS, 경로 B(B_L + B_R) 대
  경로 A, 양귀 에너지 평균, 헤드폰 EQ 이전.
- 모든 좌석에 같은 지연과 게인을 쓴다. `stimuli.csv`에는 자극마다 지연, 게인, B_L·B_R 경유 실효 ITDG, PA 선행
  여부, 실효 레벨비, RMS와 피크 레벨, 해시가 기록된다.
- 경로 A 레벨은 모든 조건에서 같다(전역 스케일 하나, 피크는 `headroom_dbfs`). 따라서 전체 음량은 계획서의 의도대로
  레벨비에 따라 바뀌며, 이는 기록된다.
- 좌석마다 경로 A 단독 자극 1개(`*_ref_pathA.wav`)를 음색 앵커로 둔다.
- 선택적 헤드폰 보정(`headphone_filter`)은 최종 믹스에만 적용한다.
- `manifest.json`에 config, 코드, 드라이 파일, BRIR의 해시(와 BRIR 세트 자체의 manifest)를 기록한다.

확인 결과: 기준 좌석에서 측정한 ITDG와 레벨비가 명목값과 같다(0.000 ms, 0.000 dB). 원 BRIR에서 클릭 자극을 모두
독립적으로 다시 만든 결과가 파일과 1.5·10⁻⁵(float32 반올림) 이내로 일치한다. 파일에서 측정한 B 경로 시작점이 기록된
실효 ITDG와 같다. 재생 레벨 교정, 제시, 무작위화, 응답 수집은 실험 프로그램의 몫이다.

## 실측 기반 보정 (`calibrate.py`)

`python calibrate.py my_hall/config.json measurements.csv --source-directivity directivity/dodeca_NTi_DS3.csv`

- `measurements.csv`: `label, src_x, src_y, src_z, rec_x, rec_y, rec_z, band_hz, T30_s, EDT_s`(위치와 옥타브 대역
  125 Hz–4 kHz마다 한 행. EDT는 선택). 합성값이 든 양식: `examples/calibration_measurements_example.csv`.
- 대역마다 계수 하나로 조정 대상 그룹(`--adjust aud,wall,ceil`. 기본은 전부)의 흡음률을 비례 조정하여, 위치 평균
  시뮬레이션 T30이 실측 평균의 2 % 이내가 될 때까지 반복한다(잔향의 JND는 5 %, ISO 3382-1 Annex A).
  갱신: k ← k·T_sim/T_meas(Sabine 비례), 계수는 0.01–0.95 범위로 제한.
- `<config>_calibrated.json`(재료 교체, 계수와 전후 값을 담은 `_calibration` 기록)과 `_report.csv` /
  `_report.md`(대역·위치별, EDT는 맞추지 않은 확인용)를 쓴다.
- 대역당 계수 하나로는 어느 면이 틀렸는지 알 수 없다. 보정과 검증은 서로 다른 위치에서 할 것.

합성 "실측"으로 확인(재료를 바꾼 그린 시험 홀, 보정 위치 2곳, 약 30초): 보정 위치의 T30 오차 −13 % → −1.3 %
(가장 나쁜 대역). 보정에 쓰지 않은 위치에서 T30 −16 % → −4 %, EDT −11 % → +3 %.

## 회절의 실측 대조 (`validate_bras.py`)

BRAS(Aspöck, Brinkmann, Ackermann, Weinzierl & Vorländer 2020, *Benchmark for Room Acoustical Simulation*, v3,
[doi:10.14279/depositonce-6726.3](https://doi.org/10.14279/depositonce-6726.3), CC BY-SA 4.0 — 페이지에서 확인할 것)에는
장면 RS5 "simple diffraction (infinite edge)"가 있다: 두께 25 mm, 높이 2.07 m의 MDF 칸막이, 스피커 높이 4 × 마이크
높이 4, Genelec 8020c, 44.1 kHz, Pa 단위 RIR(SOFA와 WAV). 저장소에 포함되지 않으며 빌드 환경에서는 접근할 수
없으므로 `1_scene_descriptions-RS5.zip`을 직접 내려받는다.

```bash
python validate_bras.py "RS5 diffraction (infinite wedge)/RIRs/RS5_RIRs.sofa" --out validation/bras_RS5
```

장면 형상은 내장되어 있다(`Geometry/RS5_RIR.png` 기준: 앞면 x = 5.487 m, 25 mm, 높이 2.066 m, 폭 4.75 m,
중심 y = 2.985 m, 단단한 바닥 z = 0). 위치는 SOFA 파일에서 읽는다. 모델: 얇은 강체 반무한 평판, 영상법으로 다룬
강체 바닥(가려지지 않은 직접·바닥 반사 경로, 회절 경로 4개), 1 m에서 0.4 Pa인 점음원(명시된 2 m에서 80 dB SPL,
1 kHz), 주파수 특성은 평탄. 실측과 예측 IR에 같은 창을 적용한다: 첫 도달 − 0.5 ms부터 측면 모서리 경유 첫 도달
− 0.3 ms까지. 2 / 창 길이 미만의 대역은 표시된다. BRAS RS5 v3로 실행(2026-11-03). 결과는 위 *모서리 회절* 항목에 있다.
RS6(유한 물체)와 RS7(좌석 dip, 블록 15개)은 다중 회절이 필요하며 이 모델에는 없다.

## 3D OBJ 홀과 그린 홀로의 변환 (`obj_to_hall.py`)

Python 엔진은 Wavefront OBJ 메시로 주어진 홀도 계산할 수 있다(`"geometry": {"mesh": {...}}`, 설명은 `geometry.py`의
메시 부분 첫머리). 브라우저 페이지는 2.5D 그대로이며, `obj_to_hall.py`가 메시 홀을 페이지의 **Load config…**로 열 수
있는 그린 홀로 바꾼다.

- 메시: 면의 감김 방향을 믿을 수 없으므로 음원 위치에서 시작하는 복셀 채우기(5 cm)로 실내를 찾는다. 각 면의 안쪽
  법선은 실내가 있는 쪽이며, 양쪽 모두 실내가 아닌 면은 버리고, 남은 면에는 2 mm 뒤에 반대 방향 쌍둥이 면을 하나
  더 둔다(면 뒤로 빠져나간 광선이 사라지지 않고 반사되도록). 재료는 OBJ 그룹 이름으로 정한다(대소문자 무시 부분
  일치. Blender가 그룹 이름에 넣는 SketchUp 태그가 그대로 쓰인다). 큰 메시는 간략화한다(`max_faces`,
  fast-simplification, MIT). 허상은 1차까지만(pyroomacoustics는 허상을 N^차수개 나열한다), 회절은 끈다(곡면을
  잘게 나눈 메시에는 쐐기가 아닌 얕은 모서리가 수천 개 있다), 면이 3000개를 넘으면 후기 음장은 등방성이다.
- 2.5D로 변환: 평면 외곽선 = 실내 복셀의 외곽선. 깊이 방향 0.25 m 구간마다 바닥 = 열마다 가장 낮은 실내 복셀의
  평면 면적 평균(객석 블록은 높아진 바닥으로 셈), 천장 = 바닥 + 구간 체적 / 구간 면적으로 두어 체적을 보존한다
  (ULH 742 → 719 m³, STC 816 → 805 m³). 돔은 폭 방향으로 뻗은 볼트가 되고, 발코니와 돌출부는 없어지며, 폭의 일부만
  덮는 물체(교탁)는 폭 전체에 걸친 높은 띠가 된다.
- 재료: 면을 안쪽 법선에 따라 2.5D의 네 그룹(바닥/무대, 천장, 벽)으로 나눈다. 2.5D 홀은 메시보다 표면적이 작으므로
  (ULH 942 → 622 m²: 객석 단의 수직면, 작은 면이 없다) 그룹별 흡음 면적 A_g를 보존하면(`--preserve sabine`) 평균 α가
  커지고 2.5D 홀이 메시보다 빨리 감쇠한다. 기본값(`--preserve eyring`)은 α_g = 1 − exp(−A_g / S_g,2.5D)로 둔다. 즉 2.5D
  그룹의 Eyring 지수를 메시 그룹의 Sabine 흡음 면적과 같게 한다. 이유: 두 3D 메시의 광선추적 T30은 Sabine에 가까웠고
  (STC 1.47 s 대 1.43 s, ULH 1 kHz 1.94 대 1.95 s), 단순한 2.5D 홀은 Eyring처럼 감쇠한다(아래 확인). ULH에서 이때 2.5D의
  T30은 125 Hz–4 kHz에서 메시보다 0.07–0.14 s 낮다. A 보존은 0.17–0.28 s, 대역마다 하나의 계수로 방 전체 Eyring 지수를
  보존하는 방식(`room-eyring`)은 0.14–0.25 s 낮았다(`validation/fratoni_ULH_preserve.md`). 재료별 Eyring 합(Millington
  형식)도 시험했으나 흡음이 강한 객석 면에 가중이 걸려 더 나빴다.
- 광선추적 자체의 확인(`validation/check_rt_eyring.py`, 12 × 9 × 7 m 슈박스, 균일 α): 산란 0.7에서 광선추적 T30은
  α = 0.05–0.3에서 Eyring과 1–3% 이내, 산란 0.1에서는 Eyring과 Sabine 사이(α = 0.3에서 Eyring보다 최대 +12%).

```bash
python obj_to_hall.py mesh_config.json --depth-axis y --stage-end min --stage-depth 2.4   # -> mesh_config_2p5d.json
```

## 실측 홀과의 실내음향 지표 대조 (`validate_fratoni.py`)

데이터: G. Fratoni, *Materials for calibrating four complex virtual environments through acoustic simulations*,
Mendeley Data, [doi:10.17632/y7xnv6xg5s.1](https://doi.org/10.17632/y7xnv6xg5s.1), CC BY 4.0(SketchUp 모델, 음원별
수음점 평균 ISO 3382-1 지표, 경계 조건, FDTD IR). 포함되지 않는다. 네 공간 중 두 곳이 이 모델에 맞는다: **ULH**(계단식
대학 강의실)와 **STC**(돔 천장의 타원형 콘서트홀), 각각 약 900 m³와 950 m³, 200석(Fratoni 2022, AIA 48° Convegno
Nazionale, ISBN 978-88-88942-62-9). 두 오페라 극장(TCB, DUS)은 박스석과 발코니가 있어 2.5D 모델 밖이다.

방법:
- 모델은 SketchUp에서 Blender를 거쳐 "Object Groups"와 "Material Groups"를 켠 OBJ로 내보냈다(SketchUp 태그가 그룹
  이름으로 남도록). ULH: 태그 4개가 데이터셋 표의 재료 4개와 같다. STC: 태그가 표의 재료 5개와 일대일로 맞지 않아
  다음과 같이 정했다(AuralPaths 쪽 판단): `shell_sidewalls`는 방향에 따라 "Plasterboard (walls)"와 "Ceiling"으로 나눔,
  `crown` → Ceiling, `seat-cushion` → Seats, `seats-wood_stage` → Wood, `floor` → Wood(표에 바닥 재료가 없음),
  `doors_organ` → Furniture. `doors_organ`을 Wood로 바꾸면 T30이 0.03–0.05 s 달라진다(`validation/fratoni_STC_doors_*.md`).
- 흡음·산란: 데이터셋의 기하음향(GA) 보정값을 그대로 썼다. 이 값은 데이터셋 저자들이 Odeon에서 맞춘 것이다(Fratoni,
  D'Orazio & Garai 2023, Forum Acusticum, Turin, [doi:10.61782/fa.2023.1114](https://doi.org/10.61782/fa.2023.1114)이
  오페라 극장에 대해 이 보정 절차를 설명한다). Odeon은 주어진 계수에 면 크기와 경로 길이에 따른 산란을 더한다
  (Christensen & Rindel 2005, Forum Acusticum, Budapest,
  [DTU Orbit](https://orbit.dtu.dk/en/publications/a-new-scattering-method-that-combines-roughness-and-diffraction-e/)).
  이 엔진에는 그 기능이 없다. 따라서 이 대조는 다른 프로그램의 보정 입력으로 이 엔진을 시험한 것이며, 이 엔진의
  보정이 아니다.
- 위치: 데이터셋에 숫자로 없다. Room_Criteria 시트의 위치 그림(평면에서 x / y, 단면에서 높이)에서 읽었으며 약 ±0.3 m
  불확실하다.
- 엔진: 허상 1차 + 광선추적(ULH 20 000개, STC 6 000개, 메시는 3 000면으로 간략화), 공기흡음 포함. 수음점마다 옥타브
  대역별 EDT, T30, C80 / C50, Ts를 구해 실측 시트처럼 수음점 평균을 내고 JND 단위로 비교했다(ISO 3382-1 부속서 A:
  EDT / T30 5%, C80 / C50 1 dB, Ts 10 ms).

결과(계산 − 실측, JND 단위. 전체 표와 그림은 `validation/fratoni_ULH.*`, `fratoni_STC.*`):

| 홀, 음원 | 모델 | T30 125 / 250 / 500 / 1k / 2k / 4k Hz | EDT 500–4k | C50 / C80 500–4k | Ts 500–4k |
|---|---|---|---|---|---|
| ULH, S1 (수음점 26) | 3D 메시 | −2.3 / −1.2 / +0.9 / +1.0 / +0.1 / −0.9 | −0.1 … +0.7 | −0.2 … +0.2 | −0.2 … +0.4 |
| | 2.5D | −3.9 / −2.1 / −0.7 / +0.1 / −1.2 / −2.5 | −1.0 … +0.9 | −0.6 … +0.3 | −0.6 … +0.6 |
| STC, S1 (10) | 3D 메시 | +6.8 / +4.1 / +4.0 / +2.3 / +3.6 / +3.5 | +3.8 … +5.2 | −1.6 … −1.0 | +2.1 … +3.1 |
| | 2.5D | +7.4 / +4.5 / +4.1 / +2.1 / +3.3 / +3.3 | +5.1 … +6.9 | −2.1 … −1.6 | +2.4 … +3.4 |
| STC, S2 (4) | 3D 메시 | +8.8 / +2.8 / +2.5 / +2.6 / +4.1 / +4.0 | +2.8 … +5.4 | −2.1 … −1.0 | +1.7 … +2.8 |
| | 2.5D | +8.6 / +2.6 / +2.0 / +1.6 / +3.2 / +3.1 | +2.1 … +4.4 | −1.6 … −0.4 | +1.2 … +2.4 |

해석:
- ULH: 500 Hz–4 kHz에서 3D 메시의 모든 지표가 실측과 약 1 JND 이내다. 125–250 Hz에서는 T30과 EDT가 1–2 JND 짧고
  C50이 약 1.3 dB 높다. 같은 입력으로 낸 Sabine 추정도 이 대역에서 짧다(125 Hz에서 1.15 s, 실측 1.56 s, 메시 체적
  742 m³). 따라서 저역의 차이는 광선추적이 아니라 입력(여기서 쓴 체적과 계수)에 있다. 2.5D 홀은 250 Hz–2 kHz에서
  메시와 0.15 s 이내다.
- STC: 두 모델 모두 약 15% 길고(1 kHz에서 1.47 s, 실측 1.32 s), 3D 메시와 2.5D 홀은 T30이 서로 0.06 s 이내로 맞으며,
  같은 입력의 Sabine 추정도 길다(1.43 s). 같은 입력의 Eyring은 실측값인 1.32 s를 주지만, 여기서는 광선추적이 거기까지
  내려가지 않는다. 흡음이 객석에 몰려 있고 외피와 돔은 거의 모두 반사하므로(α ≈ 0.1, 산란 0.02–0.05) 후기 음장이
  확산적이지 않다. 모든 산란을 0.2 또는 0.5 이상으로 올려도(`--min-scatter`) T30은 0.05 s 미만으로만 변했다. 가장
  그럴듯한 원인은 Odeon의 산란 모델에 맞춘 입력이며, 엔진 오류는 보이지 않는다(위 슈박스 확인). 2.5D 변환(돔 →
  볼트)도 원인이 아니다.
- 비교: 같은 저자들이 Odeon으로 보정한 오페라 극장 4곳도 500–1000 Hz에서 T30 −0.06 … +0.12 s, C80 −0.4 … +0.6 dB의
  차이가 남는다(Fratoni, D'Orazio & Garai 2023, 표 1). 보정된 상용 GA도 정확히 맞지는 않는다.
- 사용상 의미: ULH 같은 홀에서 GA 보정 입력을 쓰면 엔진은 중·고역의 실측 지표를 재현한다. STC처럼 비확산성이 강한
  형상의 홀에서는 자체 보정(`calibrate.py`에 실측 T30) 없이는 재현하지 못한다. 두 대조 모두 실측값이 수음점 평균이므로
  초기 도달, ITDG, PA 경로를 좌석별로 시험하지는 않는다.

```bash
python validate_fratoni.py "<dataset folder>" ULH --obj ULH_model.obj --rays 20000 --out validation/fratoni_ULH
python validate_fratoni.py "<dataset folder>" STC --obj STC_model.obj --rays 6000 --out validation/fratoni_STC
python validate_fratoni.py "<dataset folder>" STC --obj STC_model.obj --no-3d --stc-doors Wood --out validation/fratoni_STC_doors_Wood
```
변환된 홀(`validation/fratoni_*_2p5d_config.json`, 데이터셋 출처 표기와 함께 CC BY 4.0)은 페이지에서
**Load config…**로 연다. 2026-11-05 실행(CPU 2코어에서 ULH 3D 메시 64분, STC 46분).

## 실제 홀 두 곳과의 위치별 대조 (`validate_bras_cr.py`)

BRAS v3(Aspöck et al. 2020, [doi:10.14279/depositonce-6726.3](https://doi.org/10.14279/depositonce-6726.3),
CC BY-SA 4.0)에는 실제 홀 두 곳의 실측 RIR이 3D 모델·표면 정보와 함께 있다: **CR3**(실내악 홀, 3331 m³, 342석, 발코니)과
**CR4**(대학 강당, 8657 m³, 계단식 객석, 발코니). 홀마다 12면체 음원 위치 2개 × 마이크 위치 5개, RIR은 Pa 단위(44.1 kHz),
위치는 SOFA 파일에 있다. Fratoni 대조와 달리 값이 위치별이고 RIR이 있으므로 초기 반사까지 시험할 수 있다. 포함되지 않는다:
두 장면 폴더와 `3_surface_descriptions`를 받고, `Geometry/CRn.skp`를 SketchUp 재료가 그룹 이름으로 남도록 OBJ로
내보낸다(그룹에 BRAS 재료 이름 `mat_CRn_…`이 들어간다).

입력:
- 형상: 내보낸 BRAS 모델 그대로. 메시는 문서의 표면적(CR3 2759 대 2763 m², CR4는 3000면으로 간략화해 5750 대 5851 m²)과
  체적(복셀 추정 CR3 3188 대 3331 m³, CR4 8175 대 8657 m³, 복셀 띠가 4–6% 깎는다)을 재현한다. CR4는 8 cm 복셀이 필요하다
  (`--voxel 0.08`): 5 cm에서는 채우기에 6 GB 넘게 들었다.
- 재료: BRAS `fitted_estimates`(BRAS 저자들이 Eyring 식으로 실측 잔향시간에 맞춘 흡음), 1/3옥타브 값을 옥타브로 평균.
  산란은 같은 파일에서.
- 직접음: 20개 쌍 모두에서 실측 시작 시각이 거리 / c와 −0.67 … +0.07 ms 이내로 맞는다. 즉 SOFA 위치와 OBJ가 같은 좌표계다.

계산 세 가지: (a) 3D 메시, BRAS 계수 그대로, (b) LS1 위치로 이 엔진을 한 번 보정한 3D 메시(재료마다 −ln(1 − α)를 대역별
평균 T30 계산 / 실측 비로 조정)를 보정에 쓰지 않은 LS2 위치에서 판정, (c) `obj_to_hall.py`로 만든 2.5D 홀(발코니 없음,
허상 2차, 회절 없음). 광선 4000개. 광선 500개에서는 CR3의 T30이 13–33% 길게 나왔다(후기 꼬리 잡음). 잔향 지표에는 광선
수천 개를 쓸 것.

실내음향 지표(계산 − 실측, JND, 위치 평균 절대값, 500 Hz–2 kHz. 부호와 전 대역은 `validation/bras_CR3.md`, `bras_CR4.md`):

| 홀 | 모델 | EDT | T30 | C80 | C50 | Ts |
|---|---|---|---|---|---|---|
| CR3 | 3D 메시 | 3.3 | 2.9 (모두 김, +9–16%) | 1.1 | 1.0 | 1.2 |
| | 3D 보정, 보정 밖 LS2 | 1.6 | 3.7 | 0.8 | 0.9 | 0.8 |
| | 2.5D | 4.3 | 2.9 | 1.6 | 2.3 | 2.0 |
| CR4 | 3D 메시 | 2.7 | 2.2 (모두 김, +8–16%) | 1.0 | 1.0 | 1.4 |
| | 3D 보정, 보정 밖 LS2 | 1.4 | 0.7 | 1.8 | 1.8 | 1.7 |
| | 2.5D | 1.9 | 1.2 | 0.8 | 1.3 | 1.3 |

초기 반사(500 Hz–2 kHz): 엔진이 예측한 1차 허상 중 직접음 대비 −15 dB 이상, 직접음 뒤 2 ms 이후, 다른 예측 반사와 1.5 ms
이상 떨어진 것마다, 예측 시각의 1 ms 창 안 실측 에너지(직접음의 같은 창 대비 dB)와 비교했다. 대조: 2 ms 뒤의 같은 창,
직접음 뒤 3–20 ms의 무작위 시각.

| 홀 | 모델 | 개수 | 예측(중앙값) | 예측 시각의 실측 | 2 ms 뒤 실측 | 무작위 시각 실측 | 예측 − 실측(중앙값, IQR) | r |
|---|---|---|---|---|---|---|---|---|
| CR3 | 3D 메시 | 36 | −5.3 dB | −6.8 dB | −10.4 dB | −11.5 dB | +1.2 dB (+0.1 … +3.9) | 0.59 |
| | 2.5D | 27 | −5.6 | −12.0 | −10.6 | −11.5 | +3.9 (+3.4 … +8.3) | 0.30 |
| CR4 | 3D 메시 | 35 | −6.7 | −13.7 | −14.3 | −21.0 | +6.5 (+2.6 … +8.9) | 0.30 |
| | 2.5D | 29 | −6.7 | −14.2 | −14.1 | −21.0 | +6.9 (+1.5 … +9.2) | 0.34 |

해석:
- 잔향: Eyring으로 맞춘 계수를 넣으면 광선추적의 T30은 두 홀 모두 8–16% 길다(2–3 JND). CR3 메시에 균일 흡음(α = 0.2)을 주어도
  Eyring보다 24% 느리게 감쇠하지만, 같은 경로로 타일 메시 슈박스를 계산하면 Eyring을 따른다(`validation/check_rt_eyring.py`,
  `validation/check_mesh_box.py`). 즉 이 홀들의 음장은 확산적이지 않아서, Eyring으로 맞춘 계수는 광선추적에는 너무 작다.
  따라서 이 엔진을 실측 T30으로 보정해야 한다(`calibrate.py`). LS1로 보정하면 보정 밖 LS2 위치의 T30이 CR4에서는 0.7 JND
  이내가 되었지만 CR3에서는 3.7 JND 길게 남았다(보정이 옮겨지지 않았다: 모델의 LS2 위치가 LS1 위치보다 느리게 감쇠한다).
  EDT, C80 / C50, Ts는 두 홀 모두 약 1–2 JND 이내다.
- 명료도와 Ts는 보정 전 3D에서 1.0–1.4 JND(평균 절대값)다.
- 초기 반사, 3D 메시: CR3에서는 예측 반사가 실제로 있다(예측 시각의 실측 레벨이 무작위 시각보다 4.7 dB 높고 2 ms 뒤에는
  3.6 dB 떨어진다). 레벨도 +1.2 dB(중앙값)로 맞는다. CR4에서는 예측 시각의 실측 에너지가 무작위 시각보다는 높지만 2 ms 뒤의
  같은 창보다 높지 않고, 예측 레벨이 6.5 dB(중앙값) 높다. 이 홀에서는 1차 정반사를 과대평가한다. 원인은 밝히지 못했다
  (후보: 실제로는 산란하는 면을 평면으로 모델링, BRAS 모델의 단순화, 산란 손실이 없는 허상). 실제 홀에서 ITDG·레벨비를 다룰
  때는 그 홀의 초기 반사를 실측과 먼저 대조할 것.
- 2.5D 홀: 잔향·명료도는 몇 JND 이내에 머물지만, CR3에서는 예측한 반사가 실측에 없다(그 시각의 실측 레벨이 무작위 시각과 같다).
  발코니와 측면 갤러리를 2.5D 평면 × 단면으로 줄이면 개별 초기 반사, 따라서 좌석의 ITDG가 실제 홀과 대응하지 않는다. 그린
  2.5D 홀은 2.5D에 가까운 홀에서만 유효하다.
- 이 대조에서 `obj_to_hall.py`의 버그를 찾았다: 여러 조각(무대 공간, 기둥)으로 된 평면 마스크가 스스로 교차하는 외곽선 하나로
  이어졌다(CR4). 수정했다(가장 큰 조각을 씀). ULH, STC, CR3 변환은 바뀌지 않는다.

```bash
python validate_bras_cr.py "CR3 medium room (chamber music hall)" "3 Surface descriptions" --obj CR3.obj --rays 4000 --out validation/bras_CR3
python validate_bras_cr.py "CR4 large room (auditorium)" "3 Surface descriptions" --obj CR4.obj --rays 4000 --voxel 0.08 --out validation/bras_CR4
```
2026-11-05 실행(CPU 2코어에서 CR3 약 50분, CR4 약 75분). 2.5D 홀(`validation/bras_CR*_2p5d_config.json`, CC BY-SA 4.0)은
페이지에서 **Load config…**로 연다. `calibrate.py`는 이제 메시 홀에서 음원마다 한 번만 광선추적한다(그 음원의 수음점 전체를
함께).

## 좌석 dip

모델링하지 않았다. 문헌 확인 결과, 주어진 홀의 좌석 dip 필터를 예측하는 닫힌형 또는 매개변수 모델을 찾지 못했다:
Meyer, Tahvanainen, Saarelma & Lokki (2023), JASA 154(3), 1628–1639,
[doi:10.1121/10.0020826](https://doi.org/10.1121/10.0020826)는 해석적 모델들을 검토하고(Takahashi 1997: 정성적일 뿐;
Ishida 1995, Sakurai et al. 1993: 실측과 완전히 일치하지 않음) 단순화한 형상에 FDTD를 쓴다. 그 결과(80–100 Hz와
250 Hz 부근의 dip, 좌석 하부 공간·단 경사·무대 높이에 의존, 주로 초기 응답)는 좌석마다 적용할 수 있는 전달 함수가
아니다. 여기서 필터를 만들면 지어낸 매개변수가 된다. 나중에 필요하면: 좌석 구역별 실측 좌석 dip 응답(2단계 측정)을
직접음에 적용하거나, 객석을 파동 기반으로 시뮬레이션한다.

## 재현성 (`out/manifest.json`)

`run.py`는 BRIR 옆에 `manifest.json`을 쓴다: AuralPaths 버전, 사용된 config와 그 해시, 코드 파일, KU100 SOFA 파일,
헤드폰 필터의 해시, Python / NumPy 버전, 시드 방식, 모든 BRIR의 해시(오디오 샘플만. float WAV 파일에는 타임스탬프가
들어간다). 후기 잡음과 광선추적의 시드는 경로마다 고정되어 있어 같은 코드와 config는 동일한 BRIR을 낸다
(확인: 2회 실행, 24 / 24 파일 동일). 실험에 쓴 BRIR 세트에는 manifest를 함께 보관할 것.

## 데이터 기반 스피커 지향성

뷰어에서: **Layout (06) → Directivity** 버튼(각 음원 행) → SOFA 또는 CSV 파일 선택. 데이터는 그 음원에 저장되며,
조준은 아래 조준 표에서 정한다. **×**로 지운다. **Copy config**는 데이터를 config에 써 넣고
(`"directivity": {"name": …, "data": [[band_hz, plane, angle_deg, level_db], …]}`), 그래서 `run.py`가 별도 파일 없이
쓸 수 있으며 **Load config…**가 이를 복원한다.

**SOFA (전 구면)**: `Data.Real`/`Data.Imag`와 주파수 `N`을 가진 AES69 파일(FreeFieldDirectivityTF, 예: TU Berlin 악기
데이터베이스) 또는 임펄스 응답 `Data.IR`을 가진 파일. 수음점이 여럿이면(음원 주위의 마이크) 방향은
`ReceiverPosition`에서, 아니면 `SourcePosition`에서 가져온다. 좌표는 저장된 그대로(음원 기준 x 정면, y 왼쪽, z 위).
파워는 측정(예: 음별)과 각 옥타브 대역에 걸쳐 평균한 뒤 5° 간격 풍선으로 리샘플(가장 가까운 4점, 역거리 가중)하고
정면 기준으로 정규화한다. 조준은 음원의 x축을 향하게 한다. Copy config는 풍선을 저장한다
(`"directivity": {"name": …, "balloon": {"bands": […], "db": [band][el][az]}}`). config 파일에서는
`"directivity": "path/to/file.sofa"`. 확인: `examples/directivity_test_generic90.sofa`(시험 데이터: 일반 90° 패턴,
옥타브 안에서 일정, 2522방향)는 −20 dB 이상에서 일반 모델을 0.8 dB 이내(4 kHz까지는 0.4 dB)로 재현하고,
C80 / IACC E3 / 레벨비는 0.04 dB / 0.006 / 0.2 dB 이내. 브라우저와 Python의 풍선은 0.005 dB 이내로 일치한다.
브라우저에서 SOFA를 읽을 때 h5wasm 라이브러리를 jsDelivr에서 한 번 불러온다(인터넷 필요).

**정규화**: 기본으로 각 대역은 정면에서 0 dB다. 공칭 무지향 음원(12면체)에는 CSV에 `# normalize=mean` 줄을 넣는다.
그러면 각 대역이 수평 원 위 파워 평균에서 0 dB가 되어 패턴이 음원의 스펙트럼을 바꾸지 않는다. `#`로 시작하는 줄은
주석이다.

**12면체 데이터 (`directivity/`)**, 제조사 데이터시트에서 읽은 값(모델의 대표값, 수평면만. 수직면은 같다고 가정):
- `dodeca_HBK_4292L.csv`: B&K OmniPower 4292-L, Product Data BP 1689 Fig. 6, 1 / 2 / 4 / 8 kHz(1/3옥타브).
  PDF의 벡터 곡선에서 추출. 데이터시트의 기술대로 500 Hz 이하는 무지향. 리플 3 / 12 / 10 / 10 dB.
- `dodeca_NTi_DS3.csv`: NTi Audio DS3, Product Data p. 2, 1 / 2 / 4 / 5 kHz. 래스터 그림에서 추출(±0.5 dB).
  가정: 각 캡션의 첫 대역 = 실선. 리플 0.7 / 3.3 / 4.6 / 4.0 dB. 1 kHz 미만과 5 kHz 초과는 가장 가까운 측정 대역을 쓴다.
- `directivity/checks/`: 추출한 곡선을 원래 그림 위에 겹쳐 그린 것.
- `meyer_CQ-1_nominal.csv`(80° H × 40° V)와 `meyer_UPM-1P_nominal.csv`(100° × 100°): 실측 데이터 아님. Meyer Sound는
  커버리지 수치만 공개한다(상세 데이터는 MAPP 안에만 있다). 이 파일들은 공칭 커버리지에 일반 패턴을 평면별로 적용한 것이다.

config 파일에서는 일반 커버리지 패턴 대신 CSV 파일을 지정할 수도 있다:
`"directivity": "path/to/file.csv", "aim": {"az": …, "el": …}`(어느 음원이든. 예: 경로 A의 12면체나 홀의 PA 모델).
CSV 열 `band_hz, plane, angle_deg, level_db`: plane `h` = 수평 극좌표(+ = 뒤에서 볼 때 스피커의 오른쪽), `v` = 수직
극좌표(+ = 위). 한쪽만 있는 데이터(0–180°)는 대칭으로 채우고, `v`가 없으면 회전 대칭. 레벨은 대역마다 축 위에서
0 dB로 정규화하고 모델 옥타브 대역으로 보간한다(로그 주파수). 두 평면 사이는 dB로 cos²φ·Lh + sin²φ·Lv로
섞는다(φ = 축 둘레 각도): 공학적 가정이며 측정된 두 평면에서만 정확하다. 확산 성분은 같은 패턴에서 적분한 1/Q를
쓴다. 뷰어는 조준 표에 그 음원을 "Data: file"로 표시하며, 조준은 계속 수정할 수 있다.
`examples/directivity_test_generic90.csv`는 일반 90° 패턴에서 표본을 뽑은 시험 데이터다(실제 스피커 아님). 이를 쓰면
C80 / D50 / EDT / T30 / IACC가 일반 모델과 0.04 dB / 0.005 / 0.003 s / 0.001 s / 0.007 이내, 실효 레벨비가 0.2 dB
이내로 일치한다. 다른 스피커는 제조사 데이터나 직접 측정한 값을 쓸 것.

## 알려진 한계

- 그린 홀은 2.5D다: 깊이 방향 단면이 모든 x에서 같다(측면 발코니, 박스석, 폭 방향으로 달라지는 천장 반사판 없음).
  재료 그룹은 4개뿐
- OBJ 메시 홀: Python 엔진 전용. 허상 1차, 회절 없음. 그린 홀로 변환할 때 체적을 보존하고 T30이 메시와 가깝도록 흡음을
  옮기지만, 흡음이 놓인 위치는 보존하지 않는다(*3D OBJ 홀* 참조)
- 실측 홀과의 지표 대조: 계단식 강의실(ULH)에서는 500 Hz–4 kHz에서 약 1 JND 이내, 돔 천장의 타원형 홀(STC)에서는
  데이터셋의 Odeon 보정 입력으로 약 15% 길다(*실측 홀과의 실내음향 지표 대조* 참조)
- 실제 홀 두 곳과의 위치별 대조(BRAS CR3 / CR4): Eyring으로 맞춘 계수로 T30이 8–16% 김(먼저 보정할 것). 1차 반사
  레벨은 CR3에서 맞고 CR4에서 약 6.5 dB 높음. 발코니가 있는 홀의 2.5D 버전은 개별 초기 반사를 재현하지 못함
  (*실제 홀 두 곳과의 위치별 대조* 참조)
- 그린 홀의 값은 광선추적에서 나오므로 무작위 잡음을 포함한다(위 참조). 슈박스 값은 그렇지 않다
- 슈박스: 균일 흡음, 회절 없음, 확산 후기 음장. 둘 다: 허상에서는 산란을 모델링하지 않음
- 회절: 1차만, 그린 면의 직선 모서리만. 좌석 없음, 모서리 끝점 없음(위 참조)
- 좌석 dip 효과 없음(위 참조)
- 레벨비는 BRIR 에너지비(백색 입력 상당)이며 연구계획서에서 정의한 자극 RMS가 아니다. 시뮬레이터는 이를 PA 게인
  설정에만 쓰고, 청취 실험 프로그램이 계획서의 RMS 정의로 실험 레벨을 정한다
- 좌석 지도: 좌석 위치는 평면도의 방석 중심. 귀 높이는 방석 앞 0.2 m 지점의 모델 바닥에서 1.2 m(의자는 단의 뒤쪽).
  모델의 단은 직선이므로, 곡선 단의 측면 좌석은 자기 깊이의 모델 바닥을 쓴다(최대 단 하나, 약 0.3 m 차이)
- 후기 음장: 그린 홀은 광선추적으로 얻은 도래 방향을 쓴다(후기부 전체에 분포 하나). 슈박스는 이상적 확산음장.
  후기 IACC를 신뢰하기 전에 2단계 실측과 비교할 것
- 대칭 배치의 중심선 위 좌석 C에서는 IACC ≈ 1이 된다. 모델의 인공물이다
- 최근접 HRIR 선택(보간 없음)
- 감쇠가 2.5 s 분석 창 안에서 충분히 떨어지지 않으면 T30 / EDT는 빈칸으로 둔다(아주 크거나 잔향이 아주 긴 홀).
  청취에는 1.6 s BRIR을 쓴다
- `brir_proto.py`와 `run.py`의 일부 주석은 아직 한국어다
