# AuralPaths は何について検証されているか(バージョン 0.7.0)

`docs/MODEL_ja.md` の検証を短くまとめた文書である。AuralPaths の BRIR をある用途に使ってよいか、たとえば遅延した拡声(PA)経路を
含む先行音効果の聴取実験の刺激として使ってよいかを判断する人のために書いた。以下の数値はすべて `docs/MODEL_ja.md`(英語版
`docs/MODEL_en.md`)の該当節(括弧内の名称)によるものであり、方法、データ、コマンドはその節にある。AuralPaths 0.7.0 は
https://doi.org/10.5281/zenodo.24053630 として保存されている。

使用した実測データ: BRAS CR3 / CR4(Aspöck et al. 2020、[doi:10.14279/depositonce-6726.3](https://doi.org/10.14279/depositonce-6726.3)、
CC BY-SA 4.0)および Fratoni データセット(Mendeley Data、[doi:10.17632/y7xnv6xg5s.1](https://doi.org/10.17632/y7xnv6xg5s.1)、CC BY 4.0)。
位置ごとの RIR と 1 受聴位置の BRIR がある実在のホール 2 室と、受音点平均の室内音響指標があるホール 4 室である。標本は小さく、
結果はこれらのホールについてのものであり、ホール一般についてのものではない。

## 1. 検証し、一致したもの

| 項目 | 結果 | MODEL 文書の節 |
|---|---|---|
| 直接音の到来時刻 | 実測 onset が BRAS の 20 組すべてで距離 / c の −0.67 … +0.07 ms 以内 | 位置ごとの照合 |
| 直接音の ITD と ILD | KU100 の頭部で実測 BRIR と 14–18 µs、0.8–0.9 dB 以内。測定と同じ頭部(FABIAN)で 0–5 µs、0.3–0.5 dB(スピーカー 5 台 × 2 ホール) | 実測 BRIR とのバイノーラル照合 |
| 測定と同じ頭部とスピーカーでの受聴位置のオクターブスペクトル | 125 Hz–4 kHz で 1.4 dB 以内(250 Hz–1 kHz 基準) | 実測 BRIR とのバイノーラル照合 |
| 刺激生成で設定した ITDG とレベル比 | 基準座席で公称値に等しい(0.000 ms、0.000 dB)。独立に再生成したファイルと 1.5·10⁻⁵ 以内 | 聴取実験用の刺激 |
| ブラウザページ対 Python | C80 / D50 / EDT / T30 が 0.007 dB / 0.001 / 0.001 s / 0.001 s 以内、IACC_E3 は 0.035 以内(直方体ホール、36 条件) | ブラウザ対 Python |
| 実測 T30 で校正した後の残響 | 校正に用いなかった位置で T30 が 0.8 JND 以内(BRAS CR3、CR4) | 位置ごとの照合 |
| 他のプログラムで校正された入力での室内音響指標 | ULH: 500 Hz–4 kHz ですべての指標が約 1 JND 以内。DUS: 中音域の T30 が約 1 JND 以内 | 実測ホールとの室内音響指標の照合。2 つのオペラハウス |
| 独立したシミュレータ(I-Simpa SPPS)との比較 | 拡散箱で 0–4 %、CR4 で約 1–2 JND 以内 | 独立した無料シミュレータとの比較 |

## 2. 検証し、既知の差があるもの

| 項目 | 結果 | 節 |
|---|---|---|
| 校正なしの T30 | Eyring でフィットした係数で 8–11 % 長い(BRAS RIR)。バイノーラル照合の CR4 で 15–25 % 長い | 位置ごとの照合。バイノーラル照合 |
| 1 次反射音のレベル | 実測に対し中央値 +1.6 dB(CR3)、+2.7 dB(CR4)。CR4 では反射音ごとの対応が悪い | 位置ごとの照合 |
| バイノーラル受聴位置での初期エネルギーと明瞭度 | 500 Hz–1 kHz で C80 が 1–4 dB 低い。CR4 で 0–80 ms のエネルギーの 13–20 % が 20–50 ms にある(実測 5–9 %。主に天井パネル、原因は確定していない) | バイノーラル照合 |
| 初期の両耳間相互相関 IACC_E3 | 低すぎる: 実測のスピーカー指向性で 0.34 対 0.52(CR3)、0.59 対 0.83(CR4) | バイノーラル照合 |
| 後期の両耳間相互相関 IACC_L | 実測の 1/3–1/2(後期部を理想的な拡散音場として描画) | バイノーラル照合。後期の両耳間コヒーレンス |
| 入力の仮定から遠いホール | STC は約 15 % 長い。TCB(ボックス席のオペラハウス)は減衰が速すぎ、成功した検証とは数えない | 実測ホールとの室内音響指標の照合。2 つのオペラハウス |
| 描いた 2.5D ホール | 残響と明瞭度は数 JND 以内だが、バルコニーのあるホールの個々の初期反射音は再現できない | 位置ごとの照合 |
| 開発に使っておらず公開図面からモデル化したホール | Arvedi Auditorium(事後比較、2026-11-12 の修正後): T20 は 3 % 以内、無指向性音源の C80 は 1 dB 以内だが、EDT は 14–30 % 長く、指向性スピーカーでは 2–4 kHz の C80 が 1.2–2.8 dB 低い | `validation/arvedi_check.md` |

## 3. 検証していない、またはモデル化していないもの

- 同じホールの計算 BRIR と実測 BRIR を聴取者が同等に聴くかどうか: これを比較した聴取実験はない。上の検証は物理的なものであり、
  知覚的なものではない。
- 座席ディップ: オプションの座席ディップモデルなしでは BRAS RS7 で 500 Hz のディップなし、最初の列の背後で 5–11 dB
  大きい; モデルをオンにすると RS7 で音源が見える場合 1.8–2.5 dB、最初のブロックの背後 3.3–6.2 dB、400–500 Hz の
  ディップは 3 dB 以内だが約 1/3 オクターブ低く始まる、一般的な座席、実際のホールは既定の座席で 1 か所のみ確認(`docs/MODEL_ja.md`、*座席ディップ*)。3 次以上の回折(2 次は
  オプションで、BRAS RS6 でのみ確認)、エッジの端点、形状としての座席。
- スピーカーの周波数特性(指向パターンのみをモデル化)。個人の HRTF(KU100 のみ、最近傍 HRIR、補間なし)。
- 上記 7 室以外のホール、測定位置以外の座席。

## 4. 使用上の意味

- 直接音と遅延した PA 経路の時刻と方向、および刺激の ITDG とレベル比が最もよく裏づけられた部分である。実験変数が経路の遅延や
  レベルである刺激はこの部分に依拠している。
- T30、EDT、C80 をあるホールの性質として報告する前に、そのホールの実測 T30 で残響を校正する必要がある(`calibrate.py`)。
- 特定のホールの初期反射音(座席ごとのレベルと時刻)に結果が依存する場合は、先にそのホールの測定と照合する必要がある。
- 空間印象(IACC_E3、IACC_L)は実測した 2 ホールのいずれでも低く出る。これに依存する結果はその点を明記するか、実測 BRIR を用いる
  べきである。
- 計算 BRIR はホールのモデルであり、それを用いた聴取実験は実験室実験である。その結果だけでは、実際のホールでの実際の拡声において
  何が起こるかを示すことはできない。
