# AuralPaths

拡声を伴う公演のための経路分離型バイノーラルシミュレータ。LABO 1557。

> 本文書は `MODEL_en.md`(英語)の日本語訳である。内容に相違がある場合は英語版を正とする。ボタン名など画面上の表記は、実際の画面と一致させるため英語のまま残した。

ホール(シューボックス、または平面外形に床線・天井線を描いたホール)に、**拡声音源**(直接音+左右一対の PA)、任意数の
**非拡声音源**(直接音のみ)、受聴席を配置する。音源–座席の組ごとに経路別のバイノーラル室内インパルス応答(BRIR)を
作成し、公称 ITDG(初期反射音遅延時間)とレベル比の条件を与えたうえで、到来時刻、レベル、室内音響指標を出力する。

> `config.json` のホール寸法と吸音率は仮の値である。これらの数値を実在のホールの特性として読まないこと。

## 実行(macOS)

```bash
pip install pyroomacoustics sofar soundfile scipy matplotlib
# hrir/KU100.sofa = Zenodo レコード 3928297 の HRIR_FULL2DEG.sofa (Bernschütz 2013)
python run.py                    # Python による基準計算 + out/viewer.html
python hall/make_hall.py         # 基準ホールの図面(平面+断面)
python test_signals/make_sines.py
```

描画ホールは `config.json` に `geometry` ブロック(plan, floor, ceiling, materials, ism_order, rays)として記述する。
ビューアの **Copy config** がこれを書き出す。`examples/fan_hall_config.json` は傾斜客席をもつ架空の扇形ホールである:
`python run.py examples/fan_hall_config.json`(約 1.5 分、`out_fan/` に出力)。

各自のホールは、ホールごとに専用フォルダを設け、`config.json` と `out/` を置いて管理する
(例: `python run.py my_hall/config.json`)。ホールの図面およびトレースしたホールの config は本リポジトリに含まれない。

ブラウザで `out/viewer.html` を開く。SOFA ファイルがない場合、`run.py` は無指向 RIR と平面図のみを出力する。

## ビューア(`out/viewer.html`)

ページがすべての BRIR を自ら再計算するため、以下の機能は Python を再実行せずに動作する。

- **ホール形状**: **Shoebox** または **Drawn hall**。描画ホールは平面外形(任意の多角形、例: 扇形)に、奥行き方向の
  床線と天井線(傾斜客席、段、階段状・傾斜天井)を加えたものである。読み込んだ図面の上でトレースする。
  - **Trace outline**(平面): 内側の角をクリックする。最初の点のクリック、ダブルクリック、または Enter で閉じる。
    Backspace で取り消し、Esc で中止。自己交差する外形は受け付けない。**Edit corners** で角をドラッグして移動する。
  - **Trace floor / Trace ceiling**(断面): ホール後方(左)から舞台(右)へ向かってクリックする。直前の点と奥行きが
    15 cm 以内のクリックは鉛直段となる。天井は床より 1.5 m 以上高くなければならない。
  - 材料 4 種(客席床、舞台床、壁、天井)、オクターブ帯域ごとの α と散乱係数 s。
  - 虚像次数(既定 4)と光線数(下書き 10k ~ 100k)で、速度とノイズのバランスを決める。
  - 幅/奥行き/高さは図面の枠であり、トレースした形状はそれに合わせて伸縮する。
  - 配置表の高さはその位置の床からの高さであるため、座席は客席の傾斜に追従する。
  - **Dimensions** は平面に壁の長さ、断面に床・天井の高さを表示する(m)。
- **半自動トレース(どのコピーでも動作し、Claude は不要):**
  1. 平面(および断面)を読み込む。位置合わせの段階で **Set scale…** を押し、長さが既知の寸法線の両端をクリックして
     (PDF ではクリックが線の端点に吸着する)その長さを m 単位で入力する。すると枠がホールの幅と奥行きを決める
     (断面: 高さ、および平面に縮尺がなければ奥行き)。縮尺がない場合、枠は現在の寸法に合わせて伸縮する。
  2. 上記と同様にトレースする。**Snap to drawing** がオン(既定)のとき、各クリックは画面上 10 ピクセル以内で PDF
     自体の線の最も近い角・交点へ、なければ最も近い線上へ、それもなければ 5 cm グリッドへ吸着する。カーソルが
     どの場合かを示す(□ = 角、○ = 線、+ = グリッド)。**Alt** を押している間は自由に点を置ける。
     **Edit corners** も同様に吸着する。
  3. ベクトル線は CAD から書き出した PDF にのみ存在する。PNG / JPG / スキャン PDF では 5 cm グリッドを用いる。
  確認: 描画線 22 908 本を含む CAD 平面 PDF において、線の近傍でのランダムな 40 回のマウス位置がすべて角に吸着した。
  Alt を押すと吸着しない。
- **Auto-trace from PDFs…**(Claude 内で開いたウェブ版のみ。Claude に図面を読ませ、ビューア利用者の Claude 使用量を
  消費する): 平面および/または断面を選ぶ。約 1–3 分。
  1. ページが各シートをレンダリングし、PDF の描画線をすべて読み取る。
  2. Claude がシート全体を読む: 向き、室、寸法文字列 2–4 個。
  3. 縮尺 = 両端を描かれた寸法補助線に吸着させた寸法(寸法同士が一致しなければならない)。
  4. Claude が室部分を切り出した画像上で外形(平面)または床・天井線(断面)をトレースする。
  5. トレースした各辺を 0.3 m 以内の最も近い平行な描画線に吸着させ、角は線の交点として再構成する。
  6. 任意の第 2 段階: Claude が 4 枚の 2 倍拡大タイル上に描かれた自身のトレースを見て点を修正し、修正後の点を
     再び吸着させる(0.2 m)。
  7. 平面と断面を舞台前端線で揃え、両図面を結果の下に敷く。
  Claude による簡略化の内容が一覧表示される。**Undo auto-trace** で直前のホールに戻る。
  限界: 精度は Claude がシートをどれだけ正しく読めるかに依存する。壁は PDF にベクトル線がある箇所でのみ吸着する
  (PNG / JPG では Claude が定めた位置のまま)。断面の階段状客席が最も難しい(段のすぐ下に構造線がある)。
  必ず重ね描きの結果を確認し、Edit corners または再トレースで修正すること。
- **Hall**: 幅、奥行き、高さ、舞台奥行き、オクターブ帯域ごとの吸音率。舞台奥行きは入力中に舞台境界をプレビューし、
  Enter で適用される。
- **図面**: 平面図(上から見た図)と断面図(横から見た図、舞台が右)を別々に読み込める。ファイル選択、ボタン、または
  平面/断面へのドラッグ&ドロップ。PDF(1 ページ目)、PNG、JPG、SVG に対応する。読み込み後の位置合わせ段階で
  シートを回転・反転し、ホール内側を枠で指定する。枠は室内部に合わせて伸縮する。**Adjust…** で再度開く。ページは
  空の室で始まり、ファイルなしで **Show drawing** を押すと、ホール寸法と舞台奥行きに追従する内蔵の概略図(座席、
  舞台境界)が表示される。
- **寸法変更時**: ロックされていない項目はホールとともに移動する(x は幅に比例、舞台上の項目は舞台とともに、座席は
  客席の奥行きに比例、高さは不変)か、その場に留まる。
- **条件**: 公称 ITDG 0–60 ms(1 ms 刻み)、レベル比 −9 ~ +6 dB(0.5 dB 刻み)。スライダーまたは直接入力。A/B 入力も
  同じ範囲である。Python による基準値は `config.json` の格子(`conditions`: ITDG 0 / 20 / 40 / 60 ms × レベル比
  −9 / −6 / −3 / 0 / +3 / +6 dB)にのみ存在する。傾向グラフはレベル比の全範囲にわたって ITDG 0 / 20 / 40 / 60 ms を
  描き、丸印が現在の条件である。
- **PA の向き**: PA ごとにカバレッジ(Omni, 120°, 90°, 60°)、方位角(0° = ホール正面方向、+ は +x 側)、仰角
  (+ は上)。**Aim at seat** は選択した座席に向ける。`config.json` では `B_L` / `B_R` に
  `"coverage": 90, "aim": {"az": 29.7, "el": -1.4}` と記述する。
- **配置**: 平面上で音源、PA、座席をドラッグするか、x/y/z を入力する。項目ごと、または一括でロックできる。
  **Reset layout** で `config.json` の状態に戻る。
- **座席マップ**(config に `"seats"` リストをもつホール。例: 平面図から座席を一つずつトレースした場合): 全座席を
  平面上に描き、実効 ITDG(最も近い PA − 拡声直接音)またはレベル比の推定値で色分けする。PA が先に到来する座席には
  橙色の輪が付く。マウスを重ねると、座席の x/y/z、B_L・B_R 経由の ITDG、推定値が表示される。**座席をクリックすると
  L / C / R のいずれかがその位置へ移動する**(メニューで選択)。**Copy seat CSV** は現在の条件の値をコピーする。
  レベル推定値は、基準座席のレベル比に、当該座席と基準座席との直接音の差(1/r² と PA 指向性、500 / 1000 Hz)を
  加えたものである。座席ごとに室内シミュレーションを行ったものではなく、L / R 位置では BRIR エネルギー比と最大約
  1.5 dB 異なる(`run_log.txt` 参照)。
- **非拡声音源**: 最大 5 個まで追加でき、任意に削除できる。
- **Listen**: 拡声音源用のドライファイル 1 個、非拡声音源ごとに 1 個。Mix / Direct only / PA only。ヘッドホン受聴。
  **Sennheiser HD600 compensation**(config にヘッドホンフィルタが指定されていれば既定でオン)は、出力を
  Sennheiser HD600 用補正フィルタに通し、バイノーラル信号をそのヘッドホンに合わせて等化する。他のヘッドホンや
  スピーカーではオフにする。
- **Save config…**(Load config の隣): 現在の config 全体をダウンロードする(`<hall>_config_edited.json`)。ページの
  生成元の config(または読み込んだ config)に、現在のホール、音源、向き、指向性データ、座席を反映したものである。
  AuralPaths フォルダに置き、`python run.py <ファイル>` を実行する。**Copy config** は同じ JSON をコピーする。
  保存した config には `_provenance` ブロックも入る(ページのバージョン、ブラウザエンジンと 3D モデルの SHA-256、モデルの種類、
  ページの音線数・虚像次数・回折の有無、固定された音線 seed、日付)。同じページ・エンジンで保存した config を開き直すと結果が
  そのまま再現される(seed が固定: 扇形ホールで 2 回計算しヒストグラムが同一であることを確認)。別のバージョンでは結果が
  異なりうると表示する。Python はこのブロックを無視し、独自の `out/manifest.json` を書く。
- **Export BRIRs (SOFA)…**: 現在のホールの座席 × 音源すべてを 1 つの SOFA ファイルとして保存する(AES69-2022、規約
  SingleRoomSRIR 1.0)。座席・音源の組ごとに測定 1 つ、受音器 2 つ(左耳・右耳)、経路ごとの元の BRIR(時刻 0 = 音源から音が
  出た瞬間、伝搬遅延を含む、PA の遅延・ゲインなし)、長さ 1.6 秒。位置は config の座標(3D モデルではモデル座標)、
  ListenerView は座席の向き(ページの +y)である。測定の順序(「座席 | 音源」)、時刻の基準、`_provenance` の記録はファイルの
  `Comment` 属性に、KU100 HRIR のライセンス(CC BY 3.0)は `License` に入る。h5wasm で netCDF-4 の構造で書き、
  `sofar.read_sofa(verify=True)`(sofar 1.3)で確認した(値はページの BRIR と同一)。h5wasm を最初に一度インターネットから読み込む。
- **Export WAV…**: 表示中の座席の現在の条件(公称 ITDG、レベル比、Mix / Direct only / PA only)をプレーヤーで聴く通りに保存する。
  増幅音源とその遅延、PA の組と PA の遅延・ゲインを合わせたもの。ステレオ、32-bit float、正規化なし、時刻 0 = 増幅音源から音が
  出た瞬間。
- **Load config…**: config JSON を開く(例: `my_hall/config.json`。平面上へのドロップでもよい)。ページがそのホール、
  材料、音源、座席に切り替わる。**Reset to config** はページの生成元の config に戻る。

形状が `config.json` と一致している間は、ブラウザの値の横の括弧内に Python による基準値が表示される。

## モデル

### シューボックス

| 部分 | 方法 |
|---|---|
| 初期部(直接音 + 100 ms) | 12 次までのシューボックス虚像(pyroomacoustics の減衰と空気吸収)、虚像ごとに最も近い KU100 HRIR、分数遅延 |
| 後期部 | 虚像エネルギー包絡(60 次、非コヒーレント和、5 ms 平滑化)で整形したオクターブ帯域ノイズ × 拡散音場 HRTF の帯域利得。経路ごとに独立なノイズ。左右のノイズは KU100 セットの拡散音場両耳間コヒーレンス Γ(f) をもつ(後述) |
| 接続 | sin² クロスフェード 10 ms、直接音 + 100 ms から開始 |
| PA 指向性 | 一般的な軸対称パターン(工学的仮定であり、実測したスピーカーではない): 2 kHz 以上で公称 −6 dB 全角、それ以下では BW(f) = min(360°, coverage·max(1, (2000/f)^0.7)) として広がる。振幅 ((1 + cos θ)/2)^n、BW/2 で −6 dB、下限 −30 dB。すべての虚像に厳密に適用する(放射方向 = 最初の反射点の方向)。光線追跡による拡散成分は、パターンの平均エネルギー 1/(2n + 1) で調整する。極座標データで置き換えられる(「データに基づくスピーカー指向性」参照) |
| 条件 | 基準座席 C: PA 遅延 = 公称 ITDG −(PA 到来 − 拡声直接音到来)。PA ゲインでバイノーラルエネルギー比を合わせる |
| 指標 | C80, D50, Ts, EDT, T30 は拡声系の合算エネルギーヒストグラム(500 + 1000 Hz オクターブ平均)から。IACC E3 は 0–80 ms のバイノーラル和から。Python は IACC L(80 ms ~ 終端、500 / 1k / 2k Hz)および 125 / 250 Hz の IACC L も出力する |

室内音響指標には非コヒーレントな虚像エネルギー和を用いる。完全に規則的なシューボックス格子で合成した無指向波形を
帯域フィルタ処理すると後期エネルギーが過大になることが確認されたため(仮ホールで 500 Hz +9.6 dB)、現在は用いていない。

### 描画ホール

| 部分 | 方法 |
|---|---|
| 面 | 平面多角形 × 床/天井断面 → 平面多角形群(床の帯、段の鉛直面、天井の帯、断面の折れ点で分割した壁) |
| 鏡面反射 | 指定次数までの虚像。各経路を反射多角形を介して逆追跡し、遮蔽を検査する(非凸の室)。最初の 100 ms を KU100 HRIR でレンダリング |
| 拡散 | 確率的光線追跡: パワー 4π/N の光線 N 本、確率 s で Lambert 反射、受音球 r = 0.5 m。虚像と同じエネルギー単位のヒストグラム |
| 結合 | 総エネルギー = 虚像 + max(0, 光線 − 虚像)(10 ms 平滑化)。残差は初期窓内にノイズとして加える(両エンジンとも。Python は本バージョンからで、それ以前は Python BRIR の最初の 100 ms にこのエネルギーが欠けていた。約 0.5–1 dB)。総エネルギーが後期ノイズを整形する |
| Python による基準 | 同じ面を pyroomacoustics(虚像+独自の光線追跡)に渡す。`config.json` の `geometry` ブロック |

確認: シューボックスにおいて、ブラウザの虚像は pyroomacoustics と完全に一致し(虚像 62 個)、光線追跡ヒストグラムは
解析的エネルギーと ±1 dB 以内で一致する。段をもつ非凸の扇形ホール(面 31 枚)でも、虚像リストが pyroomacoustics と
完全に一致する。s = 0 の矩形描画ホールはシューボックスを再現する(T30 1.54 / 1.54 s、EDT 1.18 / 1.20 s、
C80 2.05 / 2.21 dB)。s = 0.1 では減衰が短くなる(T30 1.29 s)。描画ホールは散乱をモデル化し、シューボックスは
モデル化しないためである。

扇形試験ホールにおけるブラウザ対 Python(座席 3 か所、光線 50 000 本、互いに異なる乱数光線): C80 0.7 dB、D50 0.04、
Ts 7 ms、EDT 0.10 s、T30 0.05 s、IACC E3 0.10 以内。EDT と C80 の差は通常の JND 近傍であるため、単一座席での約 1 dB
未満の C80 差は光線追跡ノイズとして読むこと。最終的な数値には光線数を増やす。(後述の空気吸収の修正前に測定した値で
あり、この修正は 500 Hz–1 kHz の Python の値を 0.5 dB 未満変化させる。)修正後の BRIR エネルギーのブラウザ対
Python(描画試験ホール 2 件、24 経路): 最初の 100 ms で 1.0 dB、120–300 ms で 0.9 dB、0.3–1.6 s で 1.8 dB 以内
(ノイズと光線は互いに独立)。

### 鏡面反射の係数(有限反射板の大きさ、散乱損失)

描画ホールと OBJ ホール、両エンジン(`reflections.py`、`engine_geom.js` の `specFactor`。同じコードであり、4 次まで虚像
エネルギーが 2·10⁻⁶ 以内で一致)。虚像はすべての面を無限平面とみなし、吸音されないエネルギーをすべて鏡面反射する。
虚像経路の各反射に、オクターブ帯域ごとに次のエネルギー係数を掛けるようにした。

  (1 − s) · K₁ · K₂

- (1 − s): 散乱された分は鏡面経路から抜ける(光線追跡が担う)。散乱は一つの値、または帯域ごとの値(`"s": [...]`、Python。
  ページの材料表は一つの値)で与えられる。
- K₁, K₂: 反射点を通る直交 2 断面における反射板の Kirchhoff–Fresnel 係数(Rindel 2005, "Reflection of sound from
  finite-size plane and curved surfaces", 150th ASA meeting, JASA 118(3); 発表資料
  [core.ac.uk/download/13729852.pdf](https://core.ac.uk/download/13729852.pdf); 設計式は Rindel 1992, Proc. IoA 14(2),
  [PDF](https://www.ioa.org.uk/system/files/publications/JH%20RINDEL%20ACOUSTIC%20DESIGN%20OF%20REFLECTORS%20IN%20AUDITORIA.pdf)):
  K = ½[(C(v₂) − C(v₁))² + (S(v₂) − S(v₁))²]、v = 2x cos θ / √(λ a*)、a* = 2a₁a₂ / (a₁ + a₂)。x はその断面における反射点
  からパネル端までの距離、θ は入射角(入射方向を含む断面でのみ cos θ)、a₁, a₂ は音源→反射点、反射点→受音点の展開した
  経路長(高次反射への適用は工学的拡張。Rindel の式は 1 回反射用)。無限平面で K = 1、端上の点で ¼(−6 dB)。帯域中心と
  ±⅓ オクターブで平均する。
- パネル: 一つの平面上でつながった面(1 cm 以内で接し、法線の差 2° 以内)。描画ホールでは壁の各辺・床の帯・段がそれぞれ
  パネルとなるため、段や狭い帯は低域で弱く反射する。
- 実装: pyroomacoustics は受音点が聞きうる虚像のみを残し親を保存しないため、音源からすべての虚像を生成し(ブラウザ
  エンジンと同じ方式)、反射点が各面上にある壁の順序を選んで反射の順序を復元する。
- 無効化: `"geometry": {"finite_reflectors": false, "specular_scatter_loss": false}`(Python)。シューボックスは変わらない。

BRAS CR3 / CR4 の実測 1 次反射との照合(前後で同じ反射 36 / 35 個、*実在ホール 2 館との位置ごとの照合* を参照): CR4 の
予測 − 実測 の中央値 +6.5 → +2.7 dB、平均絶対値 6.1 → 5.3 dB、相関 0.30 → 0.35。CR3 は +1.2 → +1.6 dB、平均絶対値
2.8 → 2.8 dB、相関 0.59 → 0.55。CR4 の系統的な過大評価はほぼ解消したが、CR4 で反射一つ一つの精度は依然として低い。
パネルの許容角 10°(緩やかな折れを一つのパネルとする)は CR4 で +4.1 dB と悪化したため採用しなかった。描画した試験
ホールのエネルギーヒストグラムは最初の 100 ms で約 −0.1 dB 変わる(鏡面経路から抜けた分の大部分を光線追跡の拡散成分が
補う)。個々の反射は数十 dB まで変わる(小さな段、端)。

### エッジ回折(1 次、UTD)

描画ホールのみ、両エンジン(`diffraction.py`、`GEOM.edges` / `GEOM.diffract`。両実装は 1e-10 以内で一致)。
方法: 一様回折理論(UTD)、Kouyoumjian & Pathak (1974), "A uniform geometrical theory of diffraction for an edge in
a perfectly conducting surface", Proc. IEEE 62, 1448–1461
([Google Scholar](https://scholar.google.com/scholar?q=A+uniform+geometrical+theory+of+diffraction+for+an+edge+in+a+perfectly+conducting+surface))。
室内音響への適用形は Tsingos, Funkhouser, Ngan & Carlbom (2001), SIGGRAPH,
[doi:10.1145/383259.383323](https://doi.org/10.1145/383259.383323) に従う: 球面波入射、剛なくさび面とし、各面の
反射項に R = √(1 − α) を乗じる(Tsingos らと同様の経験的処理)。

| 項目 | 選択 |
|---|---|
| エッジ | 2 面が共有するすべての直線エッジのうち、室内側の角度が 180° を超えるもの(段の上端、舞台前端、天井段差、平面の入隅、2° 以上の凸の断面折れ点)。凹エッジには 1 次の項がない |
| 経路 | 音源 → エッジ上の回折点(Keller 円錐、最短経路)→ 受音点。両区間で遮蔽を検査 |
| 係数 | 32 周波数(16 Hz–24 kHz)の複素 UTD 係数。遷移関数 F(X) はべき級数(X ≤ 16)と漸近級数(X > 16)で計算 |
| レンダリング | エッジごとに到来音 1 個、回折点方向の HRIR。複素スペクトルを経路遅延とともに適用 |
| エネルギー | 同じ境界の幾何到来音(直接音、くさび 2 面での反射)との干渉を含めて虚像ヒストグラムに加える。オクターブ帯域ごとに 8 周波数で平均 |
| 切り替え | `geometry` ブロックの `"diffraction": false`、またはビューアの *Edge diffraction* |

確認(舞台前端、1 m の段、音源は舞台上 0.3 m): 直接音の影境界をまたいでエネルギーが連続である(境界のすぐ下 / 上で
250 Hz −1.0 / −0.9 dB、1 kHz −1.7 / −1.7 dB、4 kHz −3.0 / −2.9 dB)。回折がなければ 0 dB から 0 へ不連続に途切れる。
半無限平板の試験: 全音場が影境界をまたいで連続であり、高周波で自由音場振幅の半分に収束する。

実測による確認、BRAS RS5(`validate_bras.py`、結果は `validation/bras_RS5.*`): 硬い床の上に立つ高さ 2.07 m の衝立の
RIR 16 本(スピーカー高さ 4 × マイク高さ 4)を、衝立側端経由の音が到来する前に終わる窓内で、UTD + 床の鏡像と
1/3 オクターブ帯域で比較した。500 Hz–2 kHz の平均絶対差: 影領域の 11 位置で 2.2 dB、全 16 位置で 1.8 dB。
250 Hz–8 kHz では 2.1 / 1.8 dB。予測レベルは平均 0.1–1.9 dB 高く(影領域の 5 kHz 以上でより大きい)、これにはモデルが
扱っていないものが含まれる: スピーカーの応答と指向性(1 kHz の校正値のみを使用)、衝立の厚さ 25 mm、空気吸収。
4 経路の干渉パターン(低いスピーカーで 1 kHz と 3 kHz 付近のディップ)は再現される。音源または受音点が床の高さに
ある IR 3 本(LS4-MP1, LS1-MP2, LS4-MP2)では、回折経路より先に、直線距離に相当する時刻に音が到来する。衝立の透過と
考えられ(BRAS の文書にも言及がある)、これはモデル化していない。LS4-MP2 は窓も 1 ms しかない。それ以外では到来時刻は
0.1 ms 以内で一致する。

モデル化していないもの: 高次の経路(反射と組み合わさった回折、エッジ間)、エッジ端点での回折、2.5D モデルにない
物体のエッジ(座席、バルコニー前面、反射板)。反射係数による重み付けは、吸音性のくさびの解ではない。

### 方向性をもつ後期音場

従来、後期ノイズは理想的な拡散音場の両耳エネルギーと両耳間コヒーレンスを用いていた。現在は、後期音が実際に到来する
方向からこれらを求める(描画ホール)。

1. 光線追跡により、受音点ごとに、直接音 + 100 ms 以降に 64 個の方向ビン(フィボナッチ球、頭部座標系)それぞれから
   到来するエネルギーをオクターブ帯域ごとに記録する(`dirrays.py`、音源あたり光線 20 000 本、受音球 1 m。ブラウザ
   では独自の光線追跡が同じビンを埋める)。
2. ρ_d = ビンあたりのエネルギー / そのビンの HRIR 面積重み とすると、帯域ごとの耳エネルギー = Σ ρ_d·BE_d / Σ ρ_d·Ω_d、
   コヒーレンス Γ(f) = Σ ρ_d X_d / √(Σ ρ_d P_L,d · Σ ρ_d P_R,d) である。BE, X, P は各ビンに属する KU100 方向の和で
   ある(`late_dir_tables`)。Γ は複素数であり、右チャンネルがその位相を受け取る。
3. そのコヒーレンスをもつノイズ対(上記と同じ混合)を帯域ごとに一つずつ作り、従来どおりエネルギーヒストグラムで
   整形する。

一様な音場であれば厳密に拡散音場の値となる(確認: 6e−15)。後期エネルギー全体とその減衰は引き続きエネルギー
ヒストグラムから得られ、変わったのは両耳への配分とコヒーレンスのみである。シードによる後期 ILD のばらつき: 約 0.1 dB
(光線 20 000 本、1 m 球。0.5 m では 0.3–0.4 dB)。後期部全体に一つの方向分布を用いる(時間による方向の変化はない)。
方向の計算では音源を無指向とみなす。シューボックスは引き続き拡散音場である。切り替え: `binaural` の
`"late_directional": false`。

### 光線追跡エネルギーの空気吸収(修正済み)

pyroomacoustics 0.10 は光線追跡ヒストグラムから空気吸収を除いている(確認: `air_absorption` の有無でヒストグラムが
同一)。空気吸収は RIR を合成する際にのみ適用される。現在は `energy_hist` がビンごとに exp(−m c t) を適用する。修正前は、
描画ホールの Python 後期エネルギーが高周波で過大であり(描画試験ホール、直接音後 0.1–1 s: 4 kHz で +2~+3 dB、
8 kHz で +6~+11 dB、500 Hz–1 kHz で最大 +0.5 dB)、そのため 2 kHz 以上で描画ホールの Python T30 / EDT が長すぎ、
後期部が明るすぎた。現在、ブラウザと Python のヒストグラムはすべての帯域で 0.5 dB 以内で一致する(描画試験ホール、
1 経路)。シューボックスモデルは影響を受けていない。

### 後期の両耳間コヒーレンス

目標: Γ(f) = Re Σ w·H_L·H_R* / √(Σ w·|H_L|² · Σ w·|H_R|²)、KU100 の全方向(面積重み)について。すなわち、この頭部に
対する理想的な拡散音場の両耳間コヒーレンスである。2 つの独立なノイズ n1, n2 を周波数ごとに L = cos a·n1 + sin a·n2、
R = cos a·n1 − sin a·n2、a = arccos(Γ)/2 として混合する(コヒーレンス = Γ、単位パワー。Habets, Cohen & Gannot 2008,
JASA 124(5), doi:10.1121/1.2987429 の 2 チャンネルの場合)。
確認: ランダムな方向からの平面波 3000 個を KU100 HRIR でレンダリングした音場と、1/3 オクターブのコヒーレンスが 0.07
以内で一致する。KU100 では Γ は 125 Hz で約 0.9、250 Hz で 0.65、500 Hz 以上でほぼ 0 である。したがって変化は主に
500 Hz 未満に現れ(125 Hz の後期 IACC が約 0.2 から 0.9 に上昇)、標準的な 500–2000 Hz 帯域の IACC L はほとんど
変わらない。

## 聴取実験用刺激(`make_stimuli.py`)

`python make_stimuli.py examples/stimuli_example.json` は、経路分離 BRIR(`{seat}_{path}.wav`、ヘッドホン EQ なし)から
すべての刺激を作成する。同じスクリプトを両段階で用いることを想定している: AuralPaths の BRIR(`out/brir/`)と、同じ
命名規則の KU100 実測 BRIR。したがって両段階の違いは BRIR の出所のみとなる。

- 経路 A = `path_A_inputs` の和(例: ボーカル+ピアノ)を BRIR A に通したもの。経路 B = `path_B_inputs` の和
  (ボーカル)を B_L + B_R に通したもの。
- ITDG は基準座席で BRIR の立ち上がり(ピークから −20 dB 以内の最初のサンプル、先行する耳。B = B_L, B_R のうち
  早い方)に基づいて設定する。整数サンプルの遅延。負の電気的遅延はホールでは実現できないため、経路 A を遅延させて
  実装し、その旨を記録する。
- レベル比は研究計画書の定義どおり基準座席で設定する: 刺激全体にわたる耳信号の RMS、経路 B(B_L + B_R)対経路 A、
  両耳のエネルギー平均、ヘッドホン EQ 前。
- すべての座席で同じ遅延とゲインを用いる。`stimuli.csv` には刺激ごとに、遅延、ゲイン、B_L・B_R 経由の実効 ITDG、
  PA 先行の有無、実効レベル比、RMS とピークレベル、ハッシュが記録される。
- 経路 A のレベルはすべての条件で同じである(全体で一つのスケール係数、ピークは `headroom_dbfs`)。したがって全体の
  音量は計画書の意図どおりレベル比に応じて変化し、それは記録される。
- 座席ごとに経路 A 単独の刺激 1 個(`*_ref_pathA.wav`)を音色のアンカーとして置く。
- 任意のヘッドホン補正(`headphone_filter`)は最終ミックスにのみ適用する。
- `manifest.json` に config、コード、ドライファイル、BRIR のハッシュ(および BRIR セット自身の manifest)を記録する。

確認結果: 基準座席で測定した ITDG とレベル比は公称値と一致する(0.000 ms, 0.000 dB)。元の BRIR からすべてのクリック
刺激を独立に再作成した結果が、ファイルと 1.5·10⁻⁵(float32 の丸め)以内で一致する。ファイルから測定した B 経路の
立ち上がりは、記録された実効 ITDG と一致する。再生レベルの校正、提示、ランダム化、回答収集は実験プログラムの担当である。

## 実測に基づく校正(`calibrate.py`)

`python calibrate.py my_hall/config.json measurements.csv --source-directivity directivity/dodeca_NTi_DS3.csv`

- `measurements.csv`: `label, src_x, src_y, src_z, rec_x, rec_y, rec_z, band_hz, T30_s, EDT_s`(位置とオクターブ帯域
  125 Hz–4 kHz ごとに 1 行。EDT は任意)。合成値を入れた雛形: `examples/calibration_measurements_example.csv`。
- 帯域ごとに 1 つの係数で調整対象グループ(`--adjust aud,wall,ceil`。既定はすべて)の吸音率を比例調整し、位置平均の
  シミュレーション T30 が実測平均の 2 % 以内になるまで繰り返す(残響の JND は 5 %、ISO 3382-1 Annex A)。
  更新式: k ← k·T_sim/T_meas(Sabine 比例)、係数は 0.01–0.95 の範囲に制限する。
- `<config>_calibrated.json`(材料を置換し、係数と前後の値を含む `_calibration` 記録)と `_report.csv` /
  `_report.md`(帯域・位置ごと、EDT は合わせ込みに用いない確認用)を出力する。
- 帯域あたり 1 つの係数では、どの面が誤っているかは分からない。校正と検証は異なる位置で行うこと。

合成「実測」による確認(材料を変えた描画試験ホール、校正位置 2 か所、約 30 秒): 校正位置の T30 誤差 −13 % → −1.3 %
(最も悪い帯域)。校正に用いなかった位置で T30 −16 % → −4 %、EDT −11 % → +3 %。

## 回折の実測との照合(`validate_bras.py`)

BRAS(Aspöck, Brinkmann, Ackermann, Weinzierl & Vorländer 2020, *Benchmark for Room Acoustical Simulation*, v3,
[doi:10.14279/depositonce-6726.3](https://doi.org/10.14279/depositonce-6726.3), CC BY-SA 4.0 — ページで確認すること)には
シーン RS5 "simple diffraction (infinite edge)" がある: 厚さ 25 mm、高さ 2.07 m の MDF 衝立、スピーカー高さ 4 ×
マイク高さ 4、Genelec 8020c、44.1 kHz、Pa 単位の RIR(SOFA と WAV)。本リポジトリには含まれず、ビルド環境からは
アクセスできないため、`1_scene_descriptions-RS5.zip` を各自ダウンロードする。

```bash
python validate_bras.py "RS5 diffraction (infinite wedge)/RIRs/RS5_RIRs.sofa" --out validation/bras_RS5
```

シーンの形状は組み込み済みである(`Geometry/RS5_RIR.png` に基づく: 前面 x = 5.487 m、25 mm、高さ 2.066 m、
幅 4.75 m、中心 y = 2.985 m、硬い床 z = 0)。位置は SOFA ファイルから読み込む。モデル: 薄い剛な半無限平板、鏡像法で
扱う剛な床(遮蔽されない直接・床反射経路、回折経路 4 本)、1 m で 0.4 Pa の点音源(記載された 2 m で 80 dB SPL、
1 kHz)、周波数特性は平坦。実測と予測の IR に同じ窓を適用する: 最初の到来 − 0.5 ms から、側端経由の最初の到来
− 0.3 ms まで。2 / 窓長 未満の帯域は印が付く。BRAS RS5 v3 で実行(2026-11-03)。結果は上記の *エッジ回折* の項にある。
RS6(有限物体)と RS7(座席ディップ、ブロック 15 個)は多重回折を必要とし、本モデルでは扱えない。

## 3D OBJ ホールと描画ホールへの変換(`obj_to_hall.py`)

両エンジンとも Wavefront OBJ メッシュで与えたホールを計算できる(`"geometry": {"mesh": {...}}`、説明は `geometry.py`
のメッシュ部分の冒頭。ページでは **Hall → Shape → 3D model (OBJ)**、下記 *ブラウザの 3D モデル* を参照)。2 次以上の虚像と
エッジ回折が必要な場合は、`obj_to_hall.py` でメッシュホールを描画ホール(2.5D)に変換する。

- メッシュ: 面の巻き方向は信頼できないため、音源位置から始めるボクセル塗りつぶし(5 cm)で室内を求める。各面の内向き
  法線は室内側とし、両側とも室内でない面は除き、残した面には 2 mm 後方に逆向きの面を一枚加える(面の裏へ抜けた光線を
  失わずに反射させるため)。材料は OBJ のグループ名で決める(大文字小文字を区別しない部分一致。Blender がグループ名に
  書き込む SketchUp のタグがそのまま使える)。大きなメッシュは簡略化する(`max_faces`、fast-simplification、MIT)。
  虚像は 1 次まで(pyroomacoustics は虚像を N^次数 個列挙する)、回折は用いない(曲面を細分したメッシュには楔では
  ない浅いエッジが数千ある)、面が 3000 を超える場合の後期音場は等方とする。
- 2.5D への変換: 平面外形 = 室内ボクセルの外形。奥行き方向 0.25 m の区間ごとに、床 = 各列で最も低い室内ボクセルの
  平面面積平均(客席ブロックは高い床として数える)、天井 = 床 + 区間体積 / 区間面積 とし、体積を保存する
  (ULH 742 → 719 m³、STC 816 → 805 m³)。ドームは幅方向に伸びたヴォールトとなり、バルコニーと張り出しは失われ、
  幅の一部のみを覆う物体(教卓)は幅全体にわたる高い帯となる。
- 材料: 面を内向き法線により 2.5D の 4 グループ(床 / 舞台、天井、壁)に分ける。2.5D ホールはメッシュより表面積が
  小さいため(ULH 942 → 622 m²: 客席段の垂直面や小さな面がない)、グループごとの吸音面積 A_g を保存すると
  (`--preserve sabine`)平均 α が大きくなり、2.5D ホールはメッシュより速く減衰する。既定(`--preserve eyring`)では
  α_g = 1 − exp(−A_g / S_g,2.5D) とする。すなわち 2.5D グループの Eyring 指数をメッシュグループの Sabine 吸音面積に等しく
  する。両 3D メッシュの光線追跡 T30 は Sabine に近い(STC 1 kHz 1.48 s 対 1.43 s、ULH 1 kHz 1.93 対 1.95 s)。対応方式の
  選択は経験的である: ULH では 2.5D の T30 は 125 Hz–4 kHz でメッシュより、`eyring` で 0.04–0.12 s、`sabine`(A の保存)で
  0.14–0.25 s、帯域ごとに一つの係数で室全体の Eyring 指数を保存する `room-eyring` で 0.11–0.21 s 低い
  (`validation/fratoni_ULH_preserve.md`)。材料ごとの Eyring 和(Millington 型)も試したが、吸音の強い客席面に重みがかかり、
  より悪かった。(2026-11-06 までこの段落は「単純な 2.5D ホールは Eyring に従って減衰する」としていた。これは次項の音線追跡の
  エネルギー下限によるものであった。)
- 光線追跡そのものの確認(`validation/check_rt_eyring.py`、12 × 9 × 7 m のシューボックス、一様な α): 散乱 0.7 では
  光線追跡の T30 は α = 0.05–0.3 で Eyring より 7–12% 長い(Sabine に近い)。散乱 0.1 では −0.4 … +12% である。自由行程長の
  分散により平均の減衰が Eyring より遅くなる。ブラウザの追跡器もタイル直方体で同じ値を与え、自身の自由行程からの予測に従う
  (`validation/check_box_lambert.js`)。
- 音線追跡のエネルギー下限(2026-11-06 修正): pyroomacoustics は `energy_thres` を、音線を終える基準(開始エネルギーに対する
  相対値)と、散乱(「diffuse rain」)の寄与を受音点に加えるときの絶対下限の両方に使う(pyroomacoustics 0.10.1
  `libroom_src/room.cpp`、`scat_ray`)。音線 1 本の開始エネルギーは 2 / n_rays である。以前の設定 1e-9 では約 0.5 秒から散乱
  エネルギーが落ち、T30 が短く出て、音線を増やすほど短くなった(タイル直方体、s = 1: 音線 2 000 / 20 000 / 100 000 本で
  1.11 / 1.04 / 0.99 s)。`brir_proto.RT_ENERGY_THRES` は現在 1e-20 である(直方体: 音線数によらず 1.12 s、ブラウザと同じ)。
  本文書の Python の結果はすべてこの設定で再計算した。実測ホールでは T30 の変化は小さく(ULH / STC で 0.4 JND 以下、CR3
  −3 … −4%、CR4 は変化なし)、EDT と明瞭度の変化はより大きかった(CR4 で EDT +10–12%、C80 −0.3 … −0.4 dB。以下の節を参照)。

```bash
python obj_to_hall.py mesh_config.json --depth-axis y --stage-end min --stage-depth 2.4   # -> mesh_config_2p5d.json
```

### ブラウザの 3D モデル

**Hall → Shape → 3D model (OBJ)** で OBJ ファイルを開く(または `geometry.mesh` を含む config を **Load config…** で開く。
ページが保存した config には OBJ が `mesh.obj_text` として入っており、Python の config の場合は続けて OBJ ファイルを求める)。
`engine_geom.js` は `geometry.build_mesh` と同じ方法で室内を作る(室内にある最初の音源または座席から始めるボクセル塗りつぶし、
内向き法線、隠れた面の除去、裏向きの双子面、1 mm の拡張)。BRAS CR3、ボクセル 5 cm で確認: Python と同じ 4638 面、除去面
279、体積 3188 m³、同じ 1 次虚像 37 個(エネルギーの最大相対差 7 × 10⁻⁷)。

- ページの設定: 上方向の軸(SketchUp / Blender の OBJ 書き出しは y up)、平面の回転(0 / 90 / 180 / 270°、表示用。ページは
  奥行きを y 方向に表示する)、ボクセルサイズ(auto: 5 cm 以上、ブラウザのメモリのためセル 2 × 10⁷ 個以下)。モデル内の各名前
  (OBJ の材料、なければグループ)を客席床、舞台床、壁、天井、またはその名前専用の材料に対応させる。平面図と断面図はボクセルから
  投影した室内である(外形 = 0.25 m の列ごとの x の範囲、床 / 天井線 = 列ごとの最も低い床と最も高い天井)。平面図にはモデルの
  壁面も描く。音源と座席の高さは、その点の下の最も低い床から測る。
- モデル: 1 次虚像(鏡面反射係数を含む)、エッジ回折なし、境界ボリューム階層(BVH)での音線追跡。衝突後の音線の新しい方向は
  s·Lambert + (1 − s)·鏡面反射を正規化した混合である(s は帯域平均)。Python のメッシュ経路が使う pyroomacoustics の追跡器と
  同じである(pyroomacoustics 0.10.1 の `libroom_src/room.cpp`)。ただしブラウザは pyroomacoustics の追加の「diffuse rain」項
  (各衝突点から散乱エネルギーを受音点へ直接送る項)を含まない。隙間から固体の中に入った音線は終了させる(裏向きの双子面を
  2 枚続けて通る、または室内の塗りつぶしが届かなかった空間を通る区間)。固体の中で鳴り続けないようにするためである。最初に
  試した方法は、衝突ごとに Lambert と鏡面反射を帯域別の重みで無作為に選ぶもの(帯域ごとにエネルギー保存)であった。CR3 で
  T30 の帯域平均が Python より 0–20% 長かった(125 Hz で最大)ため、ページは Python の方向規則を使う。
- Python および実測との照合(`validation/check_mesh_pyjs.py`、BRAS fitted 材料、実測位置。位置の組 10 個の帯域平均、
  ブラウザ / Python / 実測):

  | | 500 Hz | 1 kHz | 2 kHz |
  |---|---|---|---|
  | CR3 T30 (s) | 1.47 / 1.40 / 1.30 | 1.52 / 1.44 / 1.34 | 1.51 / 1.43 / 1.32 |
  | CR3 C80 (dB) | 1.0 / 1.4 / 1.5 | 0.6 / 0.9 / 1.7 | 0.8 / 1.1 / 1.6 |
  | CR4 T30 (s) | 2.24 / 2.28 / 2.07 | 2.29 / 2.30 / 2.10 | 2.03 / 2.05 / 1.84 |
  | CR4 C80 (dB) | −1.1 / −0.8 / 0.2 | −1.1 / −0.8 / −0.7 | −0.5 / −0.3 / −0.1 |

  T30: ブラウザは CR3 で Python より 5–6% 長く、CR4 では 2% 以内である(音源あたり CR3 16 000 本、CR4 8 000 本)。実測 T30 に
  対してブラウザは 8–14%、Python は 7–11% 長い。C80: 両ホールともブラウザが Python より 0.2–0.4 dB 低く、EDT は 2–5% 短い。
  位置の組ごとには 2 つの追跡器の差が大きい(T30 差の絶対値の平均 6–11%)ため、帯域平均を見るか音線数を増やす。
- 1 m タイルの OBJ で作った直方体(α 0.2、`validation/check_box_lambert.js`、`validation/check_mesh_box.py`): ブラウザと
  Python の T30 は同じである(125 / 500 / 2000 Hz で s = 1: 1.12 / 1.10 / 1.06–1.07 s、s = 0.5: 1.16 / 1.14 / 1.10 s、
  s = 0.1: 1.15 / 1.14 / 1.10 s)。ブラウザは自身の自由行程からの予測に従う(s = 1 で平均 5.93 m = 4V/S、相対分散 0.35 →
  1.11 s。予測式はスクリプト内で導出: 時間 t の反射回数はほぼ正規分布なので、平均エネルギーは
  exp((ct/m)(ln(1 − α) + γ²/2 · ln²(1 − α))) で減衰し、Eyring 1.07 s より遅い)。エネルギー下限の修正前、Python は s = 1 で
  Eyring より短い 1.03 s であった。その差はブラウザではなく Python の設定にあった。
- ブラウザの diffuse rain: 試した(各衝突の散乱分を見える受音点へ直接送る、pyroomacoustics と同じ方式)。直方体では減衰は同じ
  まま音線エネルギーが約 45% 増え(T30 は変化なし)、CR3 の C80 は 0.2–0.3 dB 上がって修正後の Python と 0.1 dB 以内になったが、
  音線追跡が 3–4 倍遅くなった。速度のため採用しなかったので、ブラウザの C80 は Python より 0.2–0.4 dB 低い(JND 1 dB 未満)。
- 時間: CR3(面 2600)は約 4 秒で作られ、音源あたり 10 000 本の音線は約 25 秒かかる。ワーカーは計算のたびに室内を作り直す
  (ページとメモリを共有しない)。

## 実測ホールとの室内音響指標の照合(`validate_fratoni.py`)

データ: G. Fratoni, *Materials for calibrating four complex virtual environments through acoustic simulations*,
Mendeley Data, [doi:10.17632/y7xnv6xg5s.1](https://doi.org/10.17632/y7xnv6xg5s.1)、CC BY 4.0(SketchUp モデル、音源
ごとに受音点平均した ISO 3382-1 指標、境界条件、FDTD による IR)。同梱しない。4 空間のうち 2 つが本モデルに適合する:
**ULH**(段床の大学講義室)と **STC**(ドーム天井をもつ楕円形コンサートホール)、それぞれ約 900 m³ と 950 m³、200 席
(Fratoni 2022, AIA 48° Convegno Nazionale, ISBN 978-88-88942-62-9)。2 つのオペラハウス(TCB、DUS)はボックス席と
バルコニーをもち、2.5D モデルの範囲外である。

方法:
- モデルは SketchUp から Blender を経て、"Object Groups" と "Material Groups" を有効にした OBJ として書き出した
  (SketchUp のタグがグループ名として残るように)。ULH: 4 つのタグがデータセットの表の 4 材料と一致する。STC: タグが
  表の 5 材料と一対一に対応しないため、次のように割り当てた(AuralPaths 側の判断): `shell_sidewalls` は向きにより
  "Plasterboard (walls)" と "Ceiling" に分割、`crown` → Ceiling、`seat-cushion` → Seats、`seats-wood_stage` → Wood、
  `floor` → Wood(表に床の材料がない)、`doors_organ` → Furniture。`doors_organ` を Wood に替えると T30 は 0.02–0.06 s
  変わる(`validation/fratoni_STC_doors_*.md`)。
- 吸音・散乱: データセットの幾何音響(GA)校正値をそのまま用いた。これはデータセットの著者らが Odeon で合わせた値で
  ある(Fratoni, D'Orazio & Garai 2023, Forum Acusticum, Turin,
  [doi:10.61782/fa.2023.1114](https://doi.org/10.61782/fa.2023.1114) がオペラハウスについてこの校正手順を述べている)。
  Odeon は与えられた係数に、面の大きさと経路長に応じた散乱を加える(Christensen & Rindel 2005, Forum Acusticum,
  Budapest, [DTU Orbit](https://orbit.dtu.dk/en/publications/a-new-scattering-method-that-combines-roughness-and-diffraction-e/))。
  本エンジンにはその機能がない。したがってこの照合は、他のプログラムの校正入力で本エンジンを試験したものであり、
  本エンジンの校正ではない。
- 位置: データセットに数値としてはない。Room_Criteria シートの位置図(平面から x / y、断面から高さ)から読み取り、
  約 ±0.3 m の不確かさがある。
- エンジン: 虚像 1 次 + 光線追跡(ULH 20 000 本、STC 6 000 本、メッシュは 3 000 面に簡略化)、空気吸収あり。受音点ごとに
  オクターブ帯域別の EDT、T30、C80 / C50、Ts を求め、実測シートと同様に受音点平均を取り、JND 単位で比較した
  (ISO 3382-1 附属書 A: EDT / T30 5%、C80 / C50 1 dB、Ts 10 ms)。

結果(計算 − 実測、JND 単位。表と図の全体は `validation/fratoni_ULH.*`、`fratoni_STC.*`):

| ホール、音源 | モデル | T30 125 / 250 / 500 / 1k / 2k / 4k Hz | EDT 500–4k | C50 / C80 500–4k | Ts 500–4k |
|---|---|---|---|---|---|
| ULH, S1(受音点 26) | 3D メッシュ | −2.4 / −1.3 / +0.5 / +0.9 / −0.0 / −0.9 | −0.1 … +0.7 | −0.3 … +0.1 | −0.1 … +0.5 |
| | 2.5D | −3.8 / −2.0 / −0.5 / +0.4 / −0.9 / −2.4 | −1.2 … +1.0 | −0.8 … +0.1 | −0.5 … +0.8 |
| STC, S1(10) | 3D メッシュ | +7.0 / +4.4 / +4.1 / +2.4 / +3.6 / +3.4 | +3.8 … +5.0 | −2.0 … −1.4 | +2.3 … +3.3 |
| | 2.5D | +7.6 / +4.7 / +4.3 / +2.2 / +3.5 / +3.4 | +5.1 … +7.0 | −2.2 … −1.6 | +2.4 … +3.5 |
| STC, S2(4) | 3D メッシュ | +8.9 / +2.8 / +2.5 / +2.3 / +4.1 / +4.0 | +2.5 … +4.8 | −2.2 … −1.1 | +1.9 … +2.9 |
| | 2.5D | +8.9 / +2.7 / +2.2 / +1.8 / +3.4 / +3.3 | +2.2 … +4.4 | −1.6 … −0.4 | +1.3 … +2.5 |

解釈:
- ULH: 500 Hz–4 kHz では 3D メッシュのすべての指標が実測と約 1 JND 以内である。125–250 Hz では T30 と EDT が 1–2 JND
  短く、C50 が約 1.3 dB 高い。同じ入力による Sabine の推定もこの帯域で短い(125 Hz で 1.15 s、実測 1.56 s、メッシュ体積
  742 m³)。したがって低域の差は光線追跡ではなく入力(ここで用いた体積と係数)にある。2.5D ホールは 250 Hz–2 kHz で
  メッシュと 0.15 s 以内である。
- STC: 両モデルとも約 15% 長く(1 kHz で 1.48 s、実測 1.32 s)、3D メッシュと 2.5D ホールは T30 で互いに 0.06 s 以内で
  一致し、同じ入力による Sabine の推定も長い(1.43 s)。同じ入力の Eyring は実測値の 1.32 s を与えるが、ここでは光線
  追跡はそこまで下がらない。吸音が客席に集中し、外殻とドームはほぼすべてを反射するため(α ≈ 0.1、散乱 0.02–0.05)、
  後期音場が拡散的でない。すべての散乱を 0.2 または 0.5 以上に上げても(`--min-scatter`)T30 の変化は 0.05 s 未満で
  あった。最も考えられる原因は Odeon の散乱モデルに合わせた入力であり、エンジンの誤りは示されない(上記のシュー
  ボックスの確認)。2.5D への変換(ドーム → ヴォールト)も原因ではない。
- 比較: 同じ著者らが Odeon で校正したオペラハウス 4 館でも、500–1000 Hz で T30 −0.06 … +0.12 s、C80 −0.4 … +0.6 dB
  の差が残る(Fratoni, D'Orazio & Garai 2023, 表 1)。校正済みの商用 GA も完全には一致しない。
- 使用上の意味: ULH のようなホールで GA 校正入力を用いれば、エンジンは中・高域の実測指標を再現する。STC のように
  非拡散性の強い形状のホールでは、独自の校正(`calibrate.py` に実測 T30)なしには再現しない。いずれの照合も実測値が
  受音点平均であるため、初期到来、ITDG、PA 経路を座席ごとに試験するものではない。

```bash
python validate_fratoni.py "<dataset folder>" ULH --obj ULH_model.obj --rays 20000 --out validation/fratoni_ULH
python validate_fratoni.py "<dataset folder>" STC --obj STC_model.obj --rays 6000 --out validation/fratoni_STC
python validate_fratoni.py "<dataset folder>" STC --obj STC_model.obj --no-3d --stc-doors Wood --out validation/fratoni_STC_doors_Wood
```
変換したホール(`validation/fratoni_*_2p5d_config.json`、データセットの出典表示とともに CC BY 4.0)は、ページの
**Load config…** で開く。2026-11-05 実行、2026-11-06 鏡面反射の係数を入れて再実行(変化は 0.2 JND 以下)、続いて音線追跡の
エネルギー下限を修正して再実行(変化は 0.4 JND 以下。CPU 2 コアで ULH 3D メッシュ約 77 分、STC 38 分)。

## 実在ホール 2 館との位置ごとの照合(`validate_bras_cr.py`)

BRAS v3(Aspöck et al. 2020, [doi:10.14279/depositonce-6726.3](https://doi.org/10.14279/depositonce-6726.3)、
CC BY-SA 4.0)には、実在ホール 2 館の実測 RIR が 3D モデルと表面情報とともに含まれる: **CR3**(室内楽ホール、3331 m³、
342 席、バルコニー)と **CR4**(大学講堂、8657 m³、段床客席、バルコニー)。各ホールで十二面体音源位置 2 × マイクロホン
位置 5、RIR は Pa 単位(44.1 kHz)、位置は SOFA ファイルにある。Fratoni の照合と異なり値が位置ごとで RIR もあるため、
初期反射まで試験できる。同梱しない: 2 つのシーンフォルダと `3_surface_descriptions` を入手し、`Geometry/CRn.skp` を
SketchUp の材料がグループ名として残るよう OBJ として書き出す(グループに BRAS の材料名 `mat_CRn_…` が入る)。

入力:
- 形状: 書き出した BRAS モデルそのまま。メッシュは文書の表面積(CR3 2759 対 2763 m²、CR4 は 3000 面に簡略化して
  5750 対 5851 m²)と体積(ボクセル推定 CR3 3188 対 3331 m³、CR4 8175 対 8657 m³。ボクセル帯が 4–6% 削る)を再現する。
  CR4 には 8 cm ボクセルが必要である(`--voxel 0.08`): 5 cm では塗りつぶしに 6 GB 超を要した。
- 材料: BRAS の `fitted_estimates`(BRAS の著者らが Eyring 式で実測残響時間に合わせた吸音率)、1/3 オクターブ値を
  オクターブに平均。散乱は同じファイルから。
- 直接音: 20 組すべてで実測の立ち上がり時刻が 距離 / c と −0.67 … +0.07 ms 以内で一致する。すなわち SOFA の位置と
  OBJ は同じ座標系である。

計算は 3 通り: (a) 3D メッシュ、BRAS の係数そのまま、(b) LS1 の位置で本エンジンを一度校正した 3D メッシュ(材料ごとに
−ln(1 − α) を帯域ごとの平均 T30 計算 / 実測 比で調整)を、校正に用いていない LS2 の位置で判定、(c) `obj_to_hall.py` で
作った 2.5D ホール(バルコニーなし、虚像 2 次、回折なし)。光線 4000 本。光線 500 本では CR3 の T30 が 13–33% 長く出た
(後期の尾部のノイズ)。残響指標には数千本の光線を用いること。

室内音響指標(計算 − 実測、JND、位置平均の絶対値、500 Hz–2 kHz。符号と全帯域は `validation/bras_CR3.md`、`bras_CR4.md`)。
現在のモデル(鏡面反射の係数、音線追跡のエネルギー下限を修正)であり、括弧内は以前のエネルギー下限による直前の実行である
(*3D OBJ ホール* を参照):

| ホール | モデル | EDT | T30 | C80 | C50 | Ts |
|---|---|---|---|---|---|---|
| CR3 | 3D メッシュ | 3.0 (2.6) | 1.8 (2.7)、すべて長い、+8% | 0.8 (1.0) | 1.0 (1.6) | 1.0 (1.2) |
| | 3D 校正、校正外の LS2 | 1.8 (1.7) | 0.8 (1.6) | 0.7 (0.9) | 0.9 (1.3) | 0.7 (1.0) |
| | 2.5D | 4.4 (4.4) | 3.2 (2.9) | 2.3 (1.7) | 2.6 (2.3) | 2.4 (2.1) |

| | 3D 校正、校正外の LS2 | 2.2 (2.7) | 0.8 (0.8) | 1.3 (0.9) | 1.2 (1.3) | 2.2 (1.3) |
| | 2.5D | 2.1 (1.9) | 1.3 (1.1) | 1.5 (0.8) | 1.4 (1.4) | 1.9 (1.1) |

初期反射(500 Hz–2 kHz): エンジンが予測した 1 次虚像のうち、直接音比 −15 dB 以上、直接音の 2 ms 後以降、他の予測反射から
1.5 ms 以上離れたものそれぞれについて、予測時刻の 1 ms 窓内の実測エネルギー(直接音の同じ窓に対する dB)と比較した。
対照: 2 ms 後の同じ窓、直接音後 3–20 ms のランダムな時刻。現在のモデル(−15 dB を超える反射の集合はモデルにより変わる。

| CR4 | 3D メッシュ | 35 | −6.7 | −13.7 | −14.3 | −21.0 | +6.5 (+2.6 … +8.9) | 0.30 |

解釈:
- 残響: Eyring で合わせた係数を用いると、光線追跡の T30 は両ホールとも 8–11% 長い(500 Hz–2 kHz の帯域平均、1.6–2.3 JND)。
  光線追跡は拡散的な直方体でも Eyring より遅く減衰するため(散乱 0.7 で 7–12%、`validation/check_rt_eyring.py`、
  `validation/check_mesh_box.py`)、Eyring で合わせた係数は光線追跡には小さすぎる。したがって本エンジンを実測 T30 で校正する
  必要がある(`calibrate.py`)。LS1 で校正すると、校正外の LS2 の位置の T30 は両ホールとも 0.8 JND 以内となり、EDT、
  C80 / C50、Ts は 0.7–2.2 JND 以内である。
- 明瞭度と Ts は、校正前の 3D で 0.8–2.3 JND(平均絶対値)である。CR4 ではエネルギー下限の修正により EDT が 10–12% 長く、
  C80 が 0.3–0.4 dB 低くなり(後期の散乱エネルギーの増加)、EDT、C80、Ts が実測から離れた(EDT 2.3 → 3.7 JND)。
- 鏡面反射の係数が指標に与えた影響(以前のエネルギー下限による実行): EDT は改善(CR3 3.3 → 2.6、CR4 2.7 → 2.3 JND)、校正後の CR3 校正外の位置の T30 は改善
  (3.7 → 1.6)、C50 は悪化(CR3 1.0 → 1.6、CR4 1.0 → 1.2)、その他は ±0.2 JND 以内。ただし校正後の CR4 校正外の位置の EDT は
  1.4 → 2.7 と悪化した。C50 の変化の原因は特定できなかった。
- 初期反射、3D メッシュ: CR3 では予測反射が実在する(予測時刻の実測レベルはランダム時刻より 4.7 dB 高く、2 ms 後には
  3.6 dB 下がる)。レベルも +1.6 dB(中央値)で一致する。CR4 では予測時刻の実測エネルギーはランダム時刻より高いが 2 ms 後の
  同じ窓より高くはない。予測レベルは鏡面反射の係数の前は 6.5 dB(中央値)高く、同じ反射で係数の後は 2.7 dB である(有限
  パネル: コンクリート梁の間の白いパネルが +8.6 dB であった)。反射一つ一つでは CR4 は依然として低い(相関 0.35–0.46)。
  実在ホールで ITDG やレベル比を扱う際には、そのホールの初期反射をまず実測と照合すること。
- 2.5D ホール: 残響と明瞭度は数 JND 以内にとどまるが、CR3 では予測した反射が実測に存在しない(その時刻の実測レベルが
  ランダム時刻と同じ)。バルコニーと側方ギャラリーを 2.5D の平面 × 断面に縮約すると、個々の初期反射、したがって座席の
  ITDG は実在ホールと対応しない。描画した 2.5D ホールは 2.5D に近いホールでのみ有効である。
- この照合で `obj_to_hall.py` の不具合を見つけた: 複数の部分(舞台空間、柱)からなる平面マスクが、自己交差する一つの外形に
  つながっていた(CR4)。修正した(最大の部分を用いる)。ULH、STC、CR3 の変換は変わらない。

## 座席ディップ

モデル化していない。文献調査の結果、所与のホールの座席ディップ(seat-dip effect)のフィルタを予測する閉形式または
パラメトリックなモデルは見つからなかった: Meyer, Tahvanainen, Saarelma & Lokki (2023), JASA 154(3), 1628–1639,
[doi:10.1121/10.0020826](https://doi.org/10.1121/10.0020826) は解析的モデルを検討し(Takahashi 1997: 定性的にとどまる;
Ishida 1995, Sakurai et al. 1993: 実測と完全には一致しない)、簡略化した形状に FDTD を用いている。その結果(80–100 Hz と
250 Hz 付近のディップ、座席下部空間・段の傾斜・舞台高さに依存、主に初期応答)は、座席ごとに適用できる伝達関数ではない。
ここでフィルタを作れば、根拠のないパラメータの組となる。将来必要になれば: 座席区画ごとの実測座席ディップ応答(第 2
段階の測定)を直接音に適用するか、客席を波動ベースでシミュレーションする。

## 再現性(`out/manifest.json`)

`run.py` は BRIR の隣に `manifest.json` を出力する: AuralPaths のバージョン、使用した config とそのハッシュ、コード
ファイル・KU100 SOFA ファイル・ヘッドホンフィルタのハッシュ、Python / NumPy のバージョン、シードの方式、すべての
BRIR のハッシュ(オーディオサンプルのみ。float WAV ファイルにはタイムスタンプが含まれるため)。後期ノイズと光線追跡の
シードは経路ごとに固定されているため、同じコードと config からは同一の BRIR が得られる(確認: 2 回実行、24 / 24
ファイルが同一)。実験に用いた BRIR セットには manifest を併せて保管すること。

## データに基づくスピーカー指向性

ビューアでは: **Layout (06) → Directivity** ボタン(各音源の行)→ SOFA または CSV ファイルを選択。データはその音源に
保存され、向きは下の向き設定表で決める。**×** で削除する。**Copy config** はデータを config に書き込み
(`"directivity": {"name": …, "data": [[band_hz, plane, angle_deg, level_db], …]}`)、それにより `run.py` は別ファイル
なしで使用でき、**Load config…** で復元される。

**SOFA(全球面)**: `Data.Real`/`Data.Imag` と周波数 `N` をもつ AES69 ファイル(FreeFieldDirectivityTF、例: TU Berlin の
楽器データベース)、またはインパルス応答 `Data.IR` をもつファイル。受音点が複数ある場合(音源周囲のマイク)は方向を
`ReceiverPosition` から、そうでなければ `SourcePosition` から取る。座標は格納されたとおり(音源基準で x 正面、y 左、
z 上)。パワーは測定(例: 音ごと)と各オクターブ帯域にわたって平均したのち、5° 間隔のバルーンに再標本化し(最近傍 4 点、
逆距離重み付け)、正面基準で正規化する。向きの設定は音源の x 軸を向ける。Copy config はバルーンを保存する
(`"directivity": {"name": …, "balloon": {"bands": […], "db": [band][el][az]}}`)。config ファイルでは
`"directivity": "path/to/file.sofa"` と書く。確認: `examples/directivity_test_generic90.sofa`(試験データ: 一般 90°
パターン、オクターブ内で一定、2522 方向)は −20 dB 以上で一般モデルを 0.8 dB 以内(4 kHz までは 0.4 dB)で再現し、
C80 / IACC E3 / レベル比は 0.04 dB / 0.006 / 0.2 dB 以内である。ブラウザと Python のバルーンは 0.005 dB 以内で一致する。
ブラウザで SOFA を読む際、h5wasm ライブラリを jsDelivr から一度だけ読み込む(インターネット接続が必要)。

**正規化**: 既定では各帯域は正面で 0 dB である。公称無指向の音源(十二面体)には CSV に `# normalize=mean` の行を
加える。すると各帯域は水平円上のパワー平均で 0 dB となり、パターンが音源のスペクトルを変えない。`#` で始まる行は
コメントである。

**十二面体のデータ(`directivity/`)**、メーカーのデータシートから読み取った値(機種の代表値、水平面のみ。鉛直面は
同じと仮定):
- `dodeca_HBK_4292L.csv`: B&K OmniPower 4292-L、Product Data BP 1689 Fig. 6、1 / 2 / 4 / 8 kHz(1/3 オクターブ)。
  PDF のベクトル曲線から抽出。データシートの記載どおり 500 Hz 以下は無指向。リップル 3 / 12 / 10 / 10 dB。
- `dodeca_NTi_DS3.csv`: NTi Audio DS3、Product Data p. 2、1 / 2 / 4 / 5 kHz。ラスター図から抽出(±0.5 dB)。仮定: 各
  キャプションの最初の帯域 = 実線。リップル 0.7 / 3.3 / 4.6 / 4.0 dB。1 kHz 未満と 5 kHz 超は最も近い測定帯域を用いる。
- `directivity/checks/`: 抽出した曲線を元の図に重ねて描いたもの。
- `meyer_CQ-1_nominal.csv`(80° H × 40° V)と `meyer_UPM-1P_nominal.csv`(100° × 100°): 実測データではない。
  Meyer Sound はカバレッジの数値のみを公開している(詳細データは MAPP 内部にのみ存在する)。これらのファイルは、公称
  カバレッジに一般パターンを面ごとに適用したものである。

config ファイルでは、一般カバレッジパターンの代わりに CSV ファイルを指定することもできる:
`"directivity": "path/to/file.csv", "aim": {"az": …, "el": …}`(任意の音源。例: 経路 A の十二面体やホールの PA の機種)。
CSV の列 `band_hz, plane, angle_deg, level_db`: plane `h` = 水平極座標(+ = 背後から見てスピーカーの右)、`v` = 鉛直
極座標(+ = 上)。片側のみのデータ(0–180°)は対称に補完し、`v` がなければ回転対称とする。レベルは帯域ごとに軸上で
0 dB に正規化し、モデルのオクターブ帯域に補間する(対数周波数)。2 面の間は dB 上で cos²φ·Lh + sin²φ·Lv として混合
する(φ = 軸周りの角度): 工学的仮定であり、測定された 2 面上でのみ厳密である。拡散成分には同じパターンから積分した
1/Q を用いる。ビューアは向き設定表でその音源を "Data: file" と表示し、向きは引き続き編集できる。
`examples/directivity_test_generic90.csv` は一般 90° パターンから標本化した試験データである(実在のスピーカーではない)。
これを用いると、C80 / D50 / EDT / T30 / IACC は一般モデルと 0.04 dB / 0.005 / 0.003 s / 0.001 s / 0.007 以内、
実効レベル比は 0.2 dB 以内で一致する。他のスピーカーにはメーカーのデータまたは自ら測定した値を用いること。

## 既知の限界

- 描画ホールは 2.5D である: 奥行き方向の断面がすべての x で同じ(側面バルコニー、ボックス席、幅方向に変化する天井
  反射板はない)。材料グループは 4 つのみ
- OBJ メッシュホール: 虚像 1 次、回折なし。描画ホールへの変換では体積を保存し、T30 がメッシュに近くなるよう吸音を写すが、
  吸音の位置は保存しない(*3D OBJ ホール* を参照)。ブラウザでは平面図と断面図が投影であり(バルコニーはその列の最も低い床と
  最も高い天井としてのみ表示)、高さは最も低い床から測り、音線追跡に diffuse rain 項がない(CR3 / CR4 では T30 が
  Python と 2–6% 以内、タイル直方体では Python と同じ。C80 は 0.2–0.4 dB 低い)
- 実測ホールとの指標の照合: 段床の講義室(ULH)では 500 Hz–4 kHz で約 1 JND 以内、ドーム天井の楕円形ホール(STC)では
  データセットの Odeon 校正入力で約 15% 長い(*実測ホールとの室内音響指標の照合* を参照)
- 実在ホール 2 館との位置ごとの照合(BRAS CR3 / CR4): Eyring で合わせた係数では T30 が 8–11% 長い(先に校正すること)。
  1 次反射のレベルは中央値で +1.6 dB(CR3)、+2.7 dB(CR4)、CR4 では反射一つ一つの精度が低い。バルコニーをもつホールの 2.5D 版は個々の初期反射を再現しない
  (*実在ホール 2 館との位置ごとの照合* を参照)
- 描画ホールの値は光線追跡に由来するためランダムなノイズを含む(上記参照)。シューボックスの値は含まない
- シューボックス: 一様吸音、回折なし、拡散後期音場、虚像に散乱損失・有限サイズ係数なし(描画ホールと OBJ ホールには
  両方ある、*鏡面反射の係数* を参照)
- 回折: 1 次のみ、描画した面の直線エッジのみ。座席なし、エッジ端点なし(上記参照)
- 座席ディップ効果なし(上記参照)
- レベル比は BRIR エネルギー比(白色入力相当)であり、研究計画書で定義した刺激 RMS ではない。シミュレータはこれを
  PA ゲインの設定にのみ用い、聴取実験プログラムが計画書の RMS の定義で実験のレベルを決める
- 座席マップ: 座席位置は平面図上の座面中心。耳の高さは座面前方 0.2 m のモデル床から 1.2 m(椅子は段の後方)。モデルの
  段は直線であるため、曲線状の段の側方座席は自身の奥行き位置のモデル床を用いる(最大で段一つ、約 0.3 m のずれ)
- 後期音場: 描画ホールは光線追跡で得た到来方向を用いる(後期部全体に一つの分布)。シューボックスは理想的な拡散音場。
  後期 IACC を信頼する前に、第 2 段階の実測と比較すること
- 対称配置の中心線上の座席 C では IACC ≈ 1 となる。これはモデルの人工物である
- 最近傍 HRIR の選択(補間なし)
- 減衰が 2.5 s の分析窓内で十分に下がらない場合、T30 / EDT は空欄とする(非常に大きい、または残響が非常に長いホール)。
  聴取には 1.6 s の BRIR を用いる
- `brir_proto.py` と `run.py` の一部のコメントは韓国語のままである
